## 관측선 원칙 (CPO 발의를 기제로)

> 카메라는 수학적 구성물이 아니라 **위치·방향·속도를 가진 세계 속 물체**다.
> 항법은 실제 객체 위치 기반이다.

세 법으로 구현한다:

1. **고개의 법 하나** — 모든 비행 상태에서 드래그 = 고개 돌리기, 같은 공식
   `각 = px · (fov/화면높이) · TURN_GAIN`, 같은 부호(하늘이 손을 따라온다).
   OrbitControls 의 회전 경로는 은퇴한다(궤도 모드의 "붙잡고 돌린다" 문법 폐기 —
   문법 개정, 실측 근거는 문 0). 회랑의 look() 이 이미 이 법이었다 — 회랑이
   특례가 아니라 **회랑이 원칙**이 된다.
2. **조준의 법** — 추력은 시선 정면이 아니라 **뜻한 곳**으로 간다:
   지목된 별(호버/첫 탭) > 커서 아래 방향 > 시선 정면. 지목된 별로 나는 동안
   기수가 목표 쪽으로 서서히 정렬된다(fly-by-wire). 감속은 **목표 거리** 기준,
   목표 앞 STANDOFF 에서 선다 — 별 앞에 도착하는 것이지 스쳐 지나가는 것이 아니다.
3. **몸의 법** (R13-c) — 회랑의 눈높이·프레이밍은 걷는 몸의 것이다.

**판정 문장**: *조준 없이, 보이는 아무 별이나 골라 한 동작으로 다가가고,
도착 전에 그 작가에 대해 세 가지를 알게 된다.* (앞 절반 = R13-a, 뒤 절반 = R13-b)

## 단계

- **R13-a 관측선 물리** (이 문서의 구현 대상): 법 1·2 + 계약 + 변이.
- **R13-b 접근 안무**: 거리 사다리가 내용을 나름 — 이름(있음) → 한 줄
  (importanceReason 요약) → 관계(지목 없이도 접근한 별의 강근거 실) → 여는 문장
  (world 보유 작가) → 착륙 초대. 없는 것은 없다고: world 없는 97인은 그 단이 빈다.
- **R13-c 몸의 회랑**: corridorPose 자세 재작업 + 좁은 화면.
- **R13-d 기체 가시화**: 놋쇠 계기 문법 목업 2–3안 → CPO 판정.

## R13-a 구현 결정 (지도 워크플로 4갈래 실측 위에서)

- OrbitControls 는 **입력을 잃는다**(`controls.enabled=false`) — target 은
  북키핑(advance()·거리 계측)으로만 남는다. `controls.update()` 호출 전부 제거.
  minDistance 기입은 관성 유지(무해)하되 의미 상실을 주석으로.
- 부호 반전 두 줄(3223/3248) 삭제. 자유·궤도·당김 상태 전부에서 드래그 →
  `look()` → `turn()`(제자리 회전). `turn()` 의 게이트를 "걷기 클램프 / 그 외
  전부 회전"으로 단순화.
- `TURN_GAIN = 1.9` (grammar.ts, 단일 상수): 하늘 800px→80°(이전 151°의 절반
  — 문 0 "너무 휙휙"의 직접 처방), 회랑 1.6→1.9(±62° 클램프까지 ~620px).
- `push()` 에 조준 해소: `aimDirOf()` = hoveredId 별 방향 ‖ 마지막 포인터의
  레이 방향 ‖ 시선. 지목 별이면 `aimId` 고정, 감속 = 그 별까지 거리 기준,
  STANDOFF(=140, NAME_NEAR 안쪽) 도달 시 정지. moveCamera 자유 분기에서
  `thrust` 는 `thrustDir` 로 적분 + 기수 정렬(ALIGN_RATE rad/s).
- `settle()` 불변(thrust·walkVel 소진 — 필드 유지).
- metrics: 기존 키 전부 유지 + `aimId` 추가. pivot 계약(150) 유지 — 주시점
  북키핑 라인은 남는다.
- 하네스: verify-flight GAIN 3.3 → 실측 재보정(이론값 ≈ TURN_GAIN),
  capture-universe.mjs 동일. 부호 단일성 신계약(궤도 상태에서 같은 방향),
  조준 비행 신계약(커서 조준 + 휠만으로 도달·정지), 감속-목표 신계약.
  변이: flight 레인 needle 갱신 + 신기제 변이(정렬 제거·STANDOFF 제거·
  aimDir 제거·look 배선 제거).

## 지도가 세운 가드레일 (어기면 되돌린다)

- 별 크기는 거리 사다리에 매지 않는다 — 크기 = max(광휘, 원반) 불변(§⑭).
- 단일 소재지: 추력 입구 push() 한 곳, 반경 클램프 한 곳, 준비도 게이트 한 곳.
- metrics 필드명 = 계약 표면. settle 의 소진 대상 = thrust·walkVel.
- 손끝 두-탭 문법(첫 탭 지목·둘째 탭 이동) 불변 — 조준의 법이 오히려 이 문법을
  강화한다(지목이 곧 항법 목표).
- 프레임 diff: 변경 전 기준선은 스크래치패드 `frames-baseline-r13/`. 0-diff
  기대 클래스: `0sky-*`(초기 자세 무입력) · `5personal` · `6year-*` ·
  `8lens-linked` · `*-1sky`. 비행 프레임(`7flight-*`)은 물리가 바뀌었으므로
  **달라야 한다** — 달라지지 않으면 그게 이상 신호다.
- scene.ts 커밋 = 착륙 검수 스탬프 낡음(tests/readiness-freshness) — 게이트
  전체 재실행 + 프레임 diff 를 근거로 같은 변경에서 재검수·갱신한다.
