## 0. 무엇이 문제인가

v1 영토는 "작가별 블롭 + 노이즈 해안선"이다. 잘 작동하지만 세 가지가 없다:
사조가 땅 위에 **없고**(라벨 센트로이드뿐), 시간이 땅을 **바꾸지 못하고**
(페이더는 별·관계만 거른다), 새 작가가 올 때 땅이 어떻게 **자라는지 규칙이
없다**. 이 셋을 한 번에 푸는 문법이 필요하다 — 단, v1의 두 재산(동결 좌표 =
안정 주소, 높이 금지 = 도판 정체성)을 파괴하지 않으면서.

## 1. 주권 계층 (sovereignty grammar)

정치지리 은유를 데이터 계약으로 만든다. 핵심 원칙: **땅의 소유자는 언제나
작가다. 사조는 땅을 소유하지 않는다 — 조약이다.**

| 계층 | 엔티티 | 지도 표현 | 데이터 |
|---|---|---|---|
| 국가(nation) | 작가 | v1 블롭 그대로 (면적 = tier×관계밀도, 동결) | authors + territory.v1 |
| **연합(union)** | 사조(movement) | **조약 오버레이**: 가맹국 공유 테두리 스트로크 + 연합 문장(紋章) + 중경 연합 라벨 | movements + members (기존 데이터로 충분) |
| 도시(city) | 작품 | 링(읽기 순위)·◆항구(입문작)·점선 가도(순서) → v2에서 1급 엔티티 승격 | works + readingOrder |
| 지구/항구/교량 | 주제·번역·각색 | P2 (ux-backlog 13) | 관계 데이터 확장 필요 |

**연합 = EU 모델**의 정확한 의미: 주권(땅·면적·좌표)은 국가에 남고, 연합은
가맹국 위에 겹치는 시각 조약이다. 이래야 ① 면적 이중계상이 없고 ② 다중 가맹
(한 작가가 두 사조)이 EU+EFTA처럼 자연스럽고 ③ 동결 좌표를 건드리지 않는다.
렌더링: 가맹국 해안선 안쪽에 연합 색 세선(1px) 인셋 스트로크, 연합 센트로이드에
문장+기간 라벨("모더니즘 연합 1910–1945"), 중경 LOD 전용. 다중 가맹은 이중
인셋(주가맹 우선, weight 기준).

**"독자 분야 구축 = 본인이 한 국가"**는 이미 v1이 하고 있다(무가맹 작가 =
비동맹국). v2가 추가하는 것은 그 반대편 — 공유 사조의 가시화다.

## 2. 시대 페이더 → 지형 모핑

핵심 설계: **해안선은 움직이지 않는다. 주권 상태가 변한다.** 좌표·지형을
시뮬레이션하면 주소 안정성이 죽는다. 대신 국가마다 생애 상태를 두고 페이더가
그 상태의 크로스페이드를 구동한다:

| 상태 | 조건 (연도 y 기준) | 시각 |
|---|---|---|
| 미형성 | y < activeRange[0] | 해안선만 흐리게 (0.15), 무채움 — "아직 바다인 땅" |
| 형성기 | activeRange[0] 부근 ±5y | 채움 램프인 (모핑의 체감 구간) |
| 활동기 | activeRange 내 | v1 현재 모습 |
| 유산기 | y > activeRange[1] | 채움 유지 + 고전 파티나 틴트 — **땅은 사라지지 않는다** (누적 모드 원칙) |

연합 조약 기간: 가맹국 ≥2 활동 시작 → 오버레이 페이드인, 마지막 가맹국 활동
종료 → 페이드아웃. 페이더를 끌면 "1900: 자연주의 조약은 지고 모더니즘 조약이
떠오른다"가 지도에서 일어난다 — CPO가 말한 자연스러운 모핑이 정확히 이것이다.

구현 경로 (v2.0, 동결 좌표 무손상): 베이크에 **author-id 인덱스 텍스처** 1장
추가(픽셀→소유 국가), 런타임 셰이더가 연도 유니폼과 작가별 activeRange
룩업으로 상태 램프를 계산. 지오메트리·좌표·해안선 불변, 페이더는 순수 셰이더
크로스페이드 — 결정적이고 저렴하다.

### v2.5 — 시대 판구조론 (D2′ 비준 2026-08-17 → **출하됨**)

> 구현: `scripts/generate-territory-eras.ts`(동결 v1의 중첩 강착 침식 —
> 프론티어-연결 성장 + 시드 지터, 키프레임 8장 1850–2000, 계약 1·2·3을
> 베이크 단계와 `eras-contract` 테스트가 이중 검증), 셰이더 브래킷
> 크로스페이드(mapA/mapB/uEraMix; 전체-시기는 완전 우회로 v1 비트 보존),
> 도시 창건 연도(플레이트 베이크·라벨·마커 3층 필터, 선고 1913 실증),
> 조약 잉크는 '현재 존재하는 땅'에만 표시(landNow 마스크). QA: era-morph
> 씬 17 asserts (브래킷 4·창건 3단·바이패스·연합).

CPO: "행성은 지각이 변화하는 살아있는 구체다. 은유 시간으로 100년이면 지각
변동이 여러 번 일어날 시간이다." 옳다 — v2.0의 '해안선 불변'은 세계의 법칙이
아니라 보수적 1단이었다. 동결 좌표의 신뢰 속성이 실제로 요구하는 것은
**정지가 아니라 결정성**이다: 같은 연도는 언제나 같은 지형이면, 페이더는
주소를 깨는 게 아니라 결정적 타임머신이 된다.

**판구조 계약 4조:**

1. **결정성** — 연도 → 지형은 순수 함수 (시드 고정 키프레임 베이크).
2. **종착 동일성** — 전체 시기 보기 = 동결 v1 도판 그대로. 행성은 이 지도를
   향해 자란다; 주소록은 종착지에서 보존된다.
3. **단조 성장** — 융기한 땅은 가라앉지 않고(누적 원칙의 지질 형태), 창건된
   도시는 자리를 지킨다. 지각변동의 드라마는 성장에서 나온다: 이웃 국토가
   자라며 만이 닫히고 해협이 생기고 섬이 합쳐진다.
4. **도시 창건 연도** — 작품 도시는 출간년에 세워진다 (1915년, 변신 시 창건).

**구현 스케치:** 시대 가중치 `w_t(author) = tierBase × (1 + 0.3 ×
degreeHat) × g(그 해까지 출간 작품 비중, 생애 상태)`로 동일 베이크를
키프레임 5–8장(1880·1900·1920·1940·1960·1980·전체) 재실행 — 마지막
키프레임은 정의상 현행 v1과 일치(계약 2를 베이크 테스트로 고정). 셰이더는
인접 두 플레이트를 연도 보간으로 크로스페이드; 생애·연합 레이어는 그대로
위에 합성. towns는 출간년 이후 키프레임에만 등장.

**실측 후 결정할 비용 축:** 키프레임 플레이트의 GPU 상주(≈8×8MB) vs
브래킷 교체 시 재페인트(수십~수백 ms 히치, 비동기화 필요); 베이크 데이터
크기(ownerRle×N 또는 로드 시 재생성); 로드 시간. 단조 성장 강제는 베이크
단계에서 t 플레이트 ⊆ t+1 플레이트 검증으로 CI 게이트화한다.

## 3. 코퍼스 확장 규칙 (새 작가의 건국)

1. 신규 국가는 **친연 이웃에 인접한 공해(公海)에서만** 건국한다 — 기존
   해안선은 메이저 버전 내 불가침 (증분 레이아웃과 동일 원칙).
2. 공해 고갈 또는 편향 교정 필요 시 **메이저 레이아웃 버전**(v2→v3)을 연다.
   구버전은 "역사 지도 v1"로 열람 가능하게 보존(리뷰의 편향 고착 경고 수용).
3. 북마크·공유 URL은 좌표가 아니라 **엔티티 ID(+QID)** 로만 — 이미 그렇다.
4. 미러 세계 원칙: 어떤 실존 국경·민족 지리도 모사하지 않는다 (v1 유지).

## 4. 진실 계약 (모든 시각 변수는 등록된다)

4차 리뷰 P0-1의 일반화. 인코딩 레지스트리:

```
Encoding { channel(면적|링크기|테두리|파티나|…), metric, formula, version,
           legendKey, 한계·편향 노트 }
```

**등록된 채널 (5차 리뷰 P0-1 반영, legend-contract가 게이트):**

| 채널 | 산식/원천 | 범례 키 | 한계 노트 |
|---|---|---|---|
| 최종 면적 (전체 시기) | tierBase(2.4/1.0/0.55)×(1+0.3×degreeHat) | legendTerrain(Title) | 기본 평면; 고도는 §4¾ 렌즈 계약으로만 (D3 개정 2026-08-17) |
| 시대 면적·해안선 | g = 0.06+0.94×(0.5×건국램프±5y + 0.5×수록작 출간 비중), 동결 v1의 후방 중첩 침식 | legendEra(Title) | **계산치** — 선별 코퍼스 기반 편집 애니메이션, 측정 아님 |
| 주권 presence | lifecycleOf: 유령 0.15→형성 램프→활동 1 | legendEra | 누적/당시 두 모드 |
| 유산 파티나 | 활동 종료 후 15y 램프, max 0.85 | legendEra | 세피아 워시, 땅 불상실 |
| 도시 등장 | 작품 출간년 ≤ 페이더 연도 | legendEra | 3층 동시 필터(플레이트·라벨·마커) |
| 조약 잉크 | 가맹 해안 안쪽 인셋 세선 × treatyPresence | legendUnion | 최종-범위 기하, landNow 마스크 |
| 조약 기간 (≈) | 가맹 작가 activeRange의 ≥2 동시 활동 인터벌 | legendUnion | **계산치** — 역사적 존속 기간 아님; 공백은 병합하지 않고 잉크가 소산·재형성 |
| 도시 실루엣 (R7) | capital=readingOrder 입구(다층+첨탑) / city=랭크 내(2층) / outpost=랭크 외(1층); footprint=랭크 가중 | legendTerrainTitle | 큐레이션된 읽기 지위의 형태 번역 — 판매량·명성 아님 |
| 읽기 가도 (R7) | readingOrder 인접쌍을 잇는 점선 지표 호 | legendTerrainTitle | 큐레이션 경로 — 역사적 이동로 아님 |
| 렌즈 기복 (§4¾) | corpus-density × smoothstep(국경 거리) 음영 | lensCorpusNote (렌즈 켤 때만) | 명시 옵트인 — 꺼진 화면의 산맥은 버그 |

- 고도 도입 조건은 §4¾ 렌즈 계약으로 승격됐다 (7차 리뷰, 2026-08-17).
- 레지스트리에 없는 채널은 QA legend-contract가 실패시킨다.
- 사조의 **역사적** 기간(출처·불확실성·가입/이탈 포함)은 별도 데이터 모델이
  필요하다 — 큐레이션 전까지 화면은 ≈ 계산치만 말한다 (ux-backlog 27).

## 4¾. 렌즈 고도 계약 (7차 리뷰 비준, 2026-08-17 — 아트 테제 §⑥ 높이 조항 개정과 쌍)

높이는 **사용자가 명시적으로 선택한 렌즈의 수치**다. "위대함" 단일 축 금지는 불변.

- **기본 상태 = 평평.** 렌즈를 켜지 않은 화면에 고도가 보이면 버그다.
- 렌즈는 이 표에 등록되어야 하며(산식·데이터 범위·편향 노트), 범례가 켜진 렌즈의
  산식을 표기해야 한다. 미등록 렌즈 셰이딩은 legend-contract 위반.
- 형상 규칙: 영토 중심이 낮은 언덕, 국경으로 갈수록 해수면 — `height =
  lensValue × smoothstep(0, d0, borderDistance)`. 첫 구현은 실제 지오메트리
  변위가 아니라 **노멀/하이트 셰이딩(2.5D)**로 검증한다 (수직 슬라이스 경로).

| LensId | 산식 | 편향 노트 |
|---|---|---|
| `none` (기본) | 0 — 평면 | — |
| `corpus-density` | norm(수록작 수 + documented 관계 수) | **현재 코퍼스의 문서화 밀도**이지 문학적 품질·위대함이 아니다 — 큐레이션 편향(부록 B)이 그대로 지도가 된다는 사실을 범례에 명기 |

문헌 수용·매개성·형식 혁신 렌즈는 출처 있는 지표 데이터가 생기기 전까지 등록하지
않는다 (근거 없는 시각 채널 금지).

## 4½. 수용 용량 (CPO 2026-08-17: "행성이 담을 정보에 비해 너무 작다")

행성은 **고정 주소 공간**이다 — 판은 커지지 않고, 역사가 바다를 채운다.

- **화면 존재감**: R 100→118 (카메라·LOD 거리 불변 → 모든 다이얼 위치가
  상대적으로 더 가까워짐; overview에서 행성이 프레임 높이의 ~72%→~100%,
  독서 고도 50→32). near 플레이트 cell 8(8192px)로 동반 상향.
- **인코딩 상한**: owner 텍스처 R8 = **국가 254** (255=바다) · lifeTex 256
  (128이 먼저 터질 뻔한 상한이었다 — 상향 완료) · unionInfo 32 조약.
  254 초과 시 owner를 RG8 16비트로 올린다(셰이더 1줄).
- **영토 예비지**: 최종 도판 육지는 구체의 ~35% — 바다 ~65%가 확장 슬레이트의
  땅이다. 신규 국가는 §3 규칙대로 **공해에서 v2.5 강착 기계로 융기**한다:
  기존 해안 불가침, 새 작가의 건국이 곧 다음 판의 지각변동.
- **그리드**: 1024×513. 셀 부족 시 2× 업샘플(1024→2048)은 마칭스퀘어 등고를
  보존하는 기하 무해 경로 — 동결 v1 재베이크가 아니다.

## 5. LOD 계약 (리뷰 제안 수용)

| LOD | 의미 좌표 | 지리 좌표 | 상호작용 |
|---|---|---|---|
| far | 앵커 국가 + 지역 대표 라벨 + 연합 없음 | 지역 클러스터 (v0.1.0 출하) | 국가 선택 |
| mid | 국가 + **연합 오버레이·조약 라벨** | **화면공간 인장 군집 + "+N" 칩** (R5 출하 — 겹치면 접히고, 칩이 목록을 연다) | 국가·연합·군집 선택 |
| near | 선택 국가 성좌 + 이웃 후퇴 | 개별 국가 (간격 확보 시 자동 전개 — 같은 충돌 술어) | 국가·관계 선택 |
| reading | 도시(작품) 1급 엔티티 + 카드 | 동일 | 작품 선택 |

## 6. 렌더러 계층화 (리뷰의 1,644줄 지적과 동일 방향)

작품 도시의 1급 엔티티 승격은 이 계층화와 함께 간다:

```
Layer { update, render, pick, describe(a11y), metrics, dispose }
TerrainLayer(베이크) · NationLifecycleLayer(시대 셰이더) · UnionLayer(조약)
· CityLayer(작품 인스턴스드 마커+공유 히트) · FlowLayer(스파크) · LabelLayer
```

각 Layer가 자기 metrics를 프로브에 등록 → "눈에 보이는 실패 = 측정되는 실패"
불변식이 레이어 추가마다 자동 확장된다.

## 8. 이 문서가 하지 않는 것

코드를 바꾸지 않는다. v1 지형·좌표·아트 테제는 D1–D5 결정 전까지 현행 유지.

내려간다 (QA 씬·계약 테스트 동반).
