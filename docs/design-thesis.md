## ① 스타일 테제 — 미감의 북극성

**문학의 행성은 '읽는 관측 기기'다.** 19세기 흑금(黑金) 성좌 아틀라스의 물성 — 세피아가 스민
웜블랙 잉크 지면, 황동(brass) 기기 선, 크기 위계만으로 말하는 별 — 을 현대 데이터 시각화의
정직함으로 다시 주조한다. 화면의 주인공은 장식이 아니라 **관계 그 자체**다: 검증된 관계의
호선들이 이 지도의 유일한 오너먼트이고, 격자는 배경 무늬가 아니라 기기의 눈금이며, 글로우는
빛나야 할 이유가 있는 앵커에만 허락된다. 타이포그래피는 편집 지도의 어법을 따른다 — 명조
제목은 명판(카르투슈)처럼 조용히 서고, 밀도는 본문이 아니라 마이크로 주석(각주·눈금·룰 라인)이
만든다. 두 좌표 모드는 하나의 서사로 갈라진다: **친연성 모드는 하늘(흑금 관측)**, **지리 모드는
지도(심야 코발트 플레이트)** — 망원경에서 눈을 떼고 지도 탁자로 시선을 내리는 그 동작이다.

핵심 판정 세 가지 (실물 관찰에서 온 결론):

1. **지면 온도를 뒤집는다.** 현행 `#0b1216` 청록먹은 '차가운 SaaS 다크'의 온도다. 레퍼런스 축 1의
   웜블랙(잉크+세피아)으로 전면 전환한다. 반 스텝 절충이 아니라 온도 자체를 바꾼다 — 흑금 대비는
   금을 밝히는 것보다 바닥을 데우는 쪽이 근본이다.
2. **노드는 달걀이 아니라 별이다.** 현행 5색 파스텔 틴트는 무광의 탁한 원반으로 읽힌다(지리 모드
   유럽 밀집부에서 특히 심함). 시대층 틴트를 **항성 스펙트럼 램프**(오래된 시대=호박색 노성 →
   동시대=청백 신성)로 재정의한다. 색상 나열이 아니라 '시간=색온도'라는 실제 인코딩이 된다.
3. **모드 구분은 팔레트 반전으로.** 두 모드가 현재 시각적으로 동일하다. 레퍼런스의 코발트
   플레이트(Burritt 계열, 명도 반전 팔레트)를 지리 모드 전용으로 채택한다.

## ③ 렌더러 조형 지시 (9)

`src/globe/renderer.ts`의 실제 구현 지점에 맞춰 쓴다.

**D1 — 격자를 기기로.** `buildGraticule()`: 30°(π/6) 스텝을 **15°**로 세분, 개별 선 opacity
0.4→0.28(선은 가늘어지고 시스템은 촘촘해진다 — 축 1의 "소극적 개별 선, 강한 시스템").
**적도와 본초자오선 2개를 별도 지오메트리**로 분리해 `--line-accent` opacity 0.55 + 적도 링에
15° 간격 틱 마크(짧은 방사 대시)를 단다. 시맨틱 모드에서는 이것이 '기준환', 지리 모드에서는
실제 적도·자오선. 재질 색은 모드별 스왑(D8).

**D2 — 노드는 별.** `NODE_SCALE`을 `anchor 2.1 / major 1.1 / context 0.7`로 (현행 1.7/1.15/0.85는
위계가 밋밋 — "크기 위계가 곧 정보 위계", 앵커:컨텍스트 = 3:1). 선택 배율 1.45→1.35(링이 일하게
한다). 앵커에만 마이크로 광채: 노드 뒤에 additive blend 빌보드 스프라이트 1장(방사형 그라디언트
텍스처를 캔버스로 생성 — 외부 이미지 아님), 색 `--brass-bright`, alpha ≤0.35, 크기 노드의 ~3배.
포스트프로세싱 블룸 금지 — 광채는 이 스프라이트가 전부다.

**D3 — 선택환은 조준환(reticle).** 현행 `RingGeometry(2.6, 3.2)` 단일 후프는 둔중하다.
**가는 이중환**(예: 2.7–2.85 + 3.3–3.45) + 카디널 4점 틱으로 교체 — 천문 기기의 조준 언어.
색 `--brass` 유지. 호버환은 단일 헤어라인(2.9–3.05), `--text` 0.4.

**D4 — 화살표 절제.** `ConeGeometry(1.0, 3.0)`→**`(0.55, 1.6)`**, opacity 0.95→0.8. 방향의 제1
단서는 이미 잘 만든 소스-어둡고 타깃-밝은 정점 그라디언트(`buildEdgeGroups`의 k0/k1)다 —
화살촉은 확인 도장이지 주인공이 아니다.

**D5 — 관계선 위계 3단.** 오버뷰(비선택): 실선 0.38→**0.42**, 점선 0.30→**0.34** — 전체 뷰에서
관계망이 '은하수 밀도'로 존재감을 갖게(적용 후보 8의 v1 버전). 선택 시: 비인접 ×0.28 유지(배경
텍스처로 후퇴), 인접 0.95 + 그라디언트(전경). 이 세 단계가 화면의 주인공 = 데이터 관계를 만든다.
**(개정 2026-08-17, 7차 리뷰):** raw 은하수는 **far 원경 한정**으로 축소한다. 친연성 **중경 이하
비선택은 raw 개별선 대신 집계 항로/밀도**로 말한다 — 관계의 아름다움보다 해석 가능성이 우선.
개별선은 hover·선택이 연다.

**D6 — 라벨 2단 언어.** 작가 라벨: 산세리프 유지, letter-spacing 0.02em 추가. 선택 라벨:
`--brass-bright` + **밑 헤어라인 룰**(border-bottom 1px `--line-accent`) — 미니 명판. 운동(성좌)
라벨: 세리프 이탤릭 유지하되 letter-spacing 0.14em→**0.2em**, 색은 새 brass의 0.5 알파 — 성좌
이름은 항상 별보다 조용하다. 지리 모드 지역 라벨(추가 시): 스몰캡 크림 `--text-dim`.

**D7 — 명판(카르투슈) 크롬.** 헤더의 "작가 100 · 관계 229" 카운트를 스몰캡 + letter-spacing
0.14em + 양옆 헤어라인 룰(`--line-accent`)로 — 플레이트 캡션의 어법. 필터·상세 패널 섹션
헤드(`h3`)에 상단 헤어라인 룰 1px `--line`을 추가해 각 섹션이 판화의 구획처럼 닫히게 한다.
패널 보더는 현행 1px 유지하되 상세 패널 헤드에만 **이중 룰**(1px + 1px, 간격 2px) 허용 —
크림 판화 플레이트의 이중 보더 인용은 이 한 곳이면 충분하다.

**D8 — 대기는 림 라이트.** atmosphere 재질: 시맨틱 = `--brass` opacity **0.06**(현행 teal
0.07 폐기) — 흑금 구체의 일식 코로나. 지리 = `geoAtmosphere` opacity 0.09. 모드 전환 시 D1
격자·지면·대기 재질 색을 기존 950ms slerp와 동기해 크로스페이드(§⑤).

**D9 — 독서 거리에서 점은 장서인이 된다 (ex libris, v1.1 프로토타입).** 카메라 235→195
구간에서 구슬 노드가 마운팅 핀으로 물러나고(스케일 ×0.45까지), 그 위에 작가 원어 스크립트의
성(姓) 이니셜 인장이 현상된다 — 이중 링 스탬프 안의 川·박·А·K·م. 글리프는 큐레이션이 아니라
`names.original`에서 파생(`src/lib/seal.ts`; 인용 관습과 토큰 순서가 어긋나는 5인만
오버라이드), 폰트는 시스템 세리프 스택만 사용(폰트 페이로드 0). 텍스처는 흰색으로 그리고
`material.color`로 틴트해 선택(brassBright)·디밍 상태가 재드로잉 없이 작동한다. **색은 여전히
의미 채널이다** — 인장은 색이 아니라 문자로 개체성을 나르고, 지구본을 돌리면 라틴·키릴·
CJK·인도계·아랍 문자가 섞인 하늘 자체가 코퍼스의 탈서구 테제를 시각화한다.

## ④ 하지 말 것

- **포스트프로세싱 블룸·파티클·렌즈플레어 금지.** 광채는 D2의 앵커 스프라이트 하나뿐.
- **채도 천장.** 이 시트 밖의 순색(원색 RGB, 네온 퍼플/핑크/시안)을 어떤 상태색으로도 들이지
  않는다 — 레퍼런스 축 2의 반면교사 전체.
- **색 단독 인코딩 금지 유지.** 실선/점선·화살표·근거 뱃지 텍스트 병용은 불가침(하드 제약).
- **둥근 카드 SaaS 어법 금지.** radius 6px 초과 금지, 그림자 확대 금지, 글래스모피즘·그라디언트
  버튼 금지. 지금의 blur 오버레이 수준에서 동결.
- **가짜 질감 금지.** 종이 노이즈·스캔 텍스처·비네트 과장 없음 — 물성은 색온도와 룰 라인으로만.
- **페이지 크롬을 모드에 따라 바꾸지 않는다.** 코발트 전환은 구체 재질만(§⑤). 패널·헤더·타임
  라인이 함께 변하면 '기기를 든 채 방이 바뀌는' 착란이 된다.
- **시대층 틴트를 카테고리 무지개로 되돌리지 않는다.** 램프의 단조성(웜→쿨)이 인코딩이다.
- **라벨에 글로우·스트로크 금지.** 현행 text-shadow 1px 이상 키우지 않는다.
- **의미 없는 모션 금지.** 자동 회전·아이들 애니메이션·펄스 없음. 움직임은 사용자 행동(선택·
  모드 전환·투어)의 응답으로만.

## ⑤ 두 좌표 모드의 시각 구분 전략

**서사: 관측에서 지도로.** 친연성 모드는 하늘을 올려다보는 행위(성좌 아틀라스), 지리 모드는
지도 탁자를 내려다보는 행위(코발트 플레이트). 레퍼런스의 두 플레이트 계열이 그대로 두 모드의
원형이다 — 흑금 폴라 차트 / Burritt 코발트.

| 층 | 친연성 (하늘) | 실제 지리 (플레이트) |
|---|---|---|
| 구체 지면 | `surface #161210` 웜블랙 | `geoSurface #14223a` 심야 코발트 |
| 격자 | `--line` 0.28 + 기준환 `--line-accent` | `geoLine` 0.32 + 적도·자오선 `geoLineStrong` — 반 스텝 더 밝게: 지도는 격자가 내용이다 |
| 대기 | brass 0.06 (금 코로나) | `geoAtmosphere` 0.09 (한색 림) |
| 노드·관계선 | 공통 (별과 호선은 두 세계의 불변량 — "같은 별을 하늘에서도 지도에서도 본다") | 공통 |
| 라벨 | 운동 = 세리프 이탤릭 성좌명 | 운동 라벨 대신 지역 스몰캡 라벨(현행 지역 라벨 부재 시 v1.1) |
| 페이지 크롬 | 불변 | 불변 |

**전환 연출:** 기존 950ms 위치 slerp와 동기해 구체·격자·대기 재질 색만 lerp(THREE.Color.lerp를
easeInOut 동일 커브로). 노드는 색을 유지한 채 이동 — "별은 그대로, 세계가 바뀐다"가 전환의
문장이다. reduced-motion에서는 즉시 스왑(현행 dur 0 경로 그대로).

**왜 이 방식인가:** 두 모드의 차이는 데이터의 *투영*이지 데이터가 아니다. 노드·관계 어법을
불변으로 두고 지면만 반전하면, 사용자는 "무엇이 바뀌었나"(좌표계)를 정확히 지각하고 "무엇이
같나"(작가와 관계)를 신뢰하게 된다. 모드 오인 문제(현재 두 모드가 동일해 보임)를 팔레트 반전
한 번으로 해소하면서, 명도 반전이라는 레퍼런스의 역사적 실례를 그대로 잇는다.

## ⑥ 게임급 상호작용 헌법 (7차 리뷰 비준, 2026-08-17)

이 제품의 본체는 "정보를 공간으로 이해하게 만드는 상호작용"이다. 사진급 그래픽·콘텐츠
물량은 게임과 경쟁하지 않지만, 아래 다섯 가지는 좋은 전략 지도(《문명》·Paradox)보다
뒤처지면 안 된다:

1. **즉시성** — 내가 무엇을 가리키고 선택했는지 즉시 안다 (hover p95 ≤50ms, 접촉 피드백 ≤50ms).
2. **의미 기반 줌** — 줌 단계마다 다른 종류의 질문과 행동이 질서 있게 열린다 (단순 확대가 아니다).
3. **반응하는 세계** — 세계가 입력에 반응하고, 그 반응이 데이터의 의미를 설명한다.
4. **카메라 주권** — 카메라는 예측 가능하고 사용자가 언제든 끊거나 되돌릴 수 있다
   (자동 이동은 1프레임 내 취소, 상태 복귀 북마크).
5. **행동 지속** — 복잡한 세계를 보면서도 다음 행동을 잃지 않는다 (상태별 컨텍스트 키).

**게임에서 가져오지 않는 것:** 의미 없는 장식·자원 수집 은유·과도한 이펙트·근거 없는
점수화. 출처·근거 수준·방향·불확실성은 게임보다 **더** 엄격하다.

**수명주기 원칙:** 연출(FlowStory)의 시계는 지오메트리 재구축과 분리된 별개 수명을
갖는다 — 카메라·LOD·패널 변화만으로 phase가 초기화되면 그것은 버그다. 스토리 리셋은
선택 변경 또는 명시적 재생 요청뿐이다.

**개정 2건:** "작품 카드는 카메라를 절대 움직이지 않는다" → 사용자 통제권(취소 가능)을
보존하는 한 **safe-area reframe 허용** — 선택 대상이 패널 아래 가려진 채 남는 것이
더 큰 실패다. "높이 금지" → 아트 테제 §⑥·문법 §4¾ 렌즈 고도 계약으로 개정.

**범위 동결 (수직 슬라이스 통과 전):** 갤럭시·작가 추가·새 페이지 보류. 문법이 통과하기
전에 데이터를 늘리면 시인성 문제만 확대된다.

## 부록 A — 검증

대비 실측 스크립트(WCAG 2.x 상대휘도식, 27개 체크 전부 통과)는 세션 스크래치패드
`contrast.mjs`로 실행했다. 재검증이 필요하면 이 표의 (fg, bg, 기준) 쌍을 동일 식으로 계산하면
된다. 요지: 텍스트 3단·brass·teal·red 전부 패널/오버레이 위 ≥4.5, 관계 6색은 양 모드 구체
지면 위 ≥3.0(그래픽 객체 기준), 포커스 링 ≥3.0.

주의 1 — `--text-faint`는 이번 상향(4.8:1)으로 '본문 기준' 통과가 됐지만, 디밍 상태 라벨
(`.is-dim`, opacity 0.55)은 의도된 비강조 상태로 4.5 예외를 유지한다(포커스 시 승격되므로).

주의 2 — 관계 6색 중 최근접 쌍은 influence(40°)·mentorship(28°)이다. 유향 실선끼리라 색이
가까울 때의 최종 방어선은 범례 스와치와 클릭 다이얼로그의 유형 명칭이며, 이는 현행 UI에 이미
있다. 색만으로 관계를 구분하지 않는다는 하드 제약이 이 쌍의 안전망이다.
