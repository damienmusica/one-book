# R11 성계 — 6인 관찰 테스트 프로토콜

주문: CPO (2026-08-20) — 수리 후 **R11 단독** 6인 관찰. 준비된 착륙지와 미준비
궤도 경험을 **모두** 포함한다. 그전까지 성계 통합·수익화·범위 확장 금지.

> **범위 축소 (CPO, 2026-08-20)**: 1단계는 **이해도·탐색만** 본다.
> **경외·잔류 기각 조건은 최소 시각 목표 슬라이스가 완성될 때까지 사용하지
> 않는다** — 프로토타입의 마감도로 미감 가설을 기각하면 구조가 아니라 미완성을
> 판정하게 된다. 아래 §4 에 유예된 지표를 따로 묶어 두었다.

> **개정 3 (CPO 비준 2026-08-24, 외부 검토 2차 회신 A·B·D)**: 단계가 하나 앞에
> 생겼다. **0단계 = 카프카 골든 저니 + 3인 비공식 욕망 테스트(§7)** 가 먼저고,
> 이 6인 관찰(1단계)은 0단계가 CPO 의 15분과 §7 의 사전 등록 기각 조건을 통과한
> 뒤에만 연다. 왜: 알려진 마감 부족을 참가자에게 재확인시키는 것은 사용자
> 테스트가 아니라 외부 QA 다. 또한 **욕망은 "멋있다"가 아니라 행동 4종으로
> 잰다**(§4 욕망 행, §4.1 (g)) — 경외 발화·잔류 시간은 기록·보고에 남고, 판정은
> 행동이 한다. 재방문(다섯째 행동)은 한 세션에서 잴 수 없으므로 §5 에 남는다.

> **개정 4 (CPO 비준 2026-08-24, R12-c 서가 회랑)**: 착륙 문법이 연도 서가에서
> **서가 회랑**으로 바뀌어(테제 §⑦) §3.2 카드 3 · §4 회랑 4행 · §4.1 (e)(f) ·
> 부록 A·C 를 회랑 문법으로 맞췄다. 소장의 정직성은 **"당긴 책의 표지가
> 실물/민장정으로 갈린다"**로 재정의됐고(쉬는 권은 전원 책등 — 서가에서 소장은
> 보이지 않는다), 기록 행 후보 둘(사망선 뒤 빈 칸 · 이륙의 자발 발견)이 붙었다.
> 부록 B 카드 문구는 경로를 쓰지 않으므로 그대로다.

**이 테스트가 존재하는 이유**: 유닛 계약과 여정 계약은 시스템이 의도대로
작동한다는 것만 증명한다. 그 의도가 사람을 설레게 한다는 것은 아무것도 증명하지
않는다. 테제 §⑩ 의 통합 조건 1–4 가 요구하는 사람 증거가 여기다.

## 0. 왜 R10 과 비교하지 않는가

외부 리뷰는 R10/R11 교차 배정을 제안했다. **채택하지 않는다.** R10 은 출하된
완성 빌드이고 R11 은 프로토타입이다 — 나란히 놓으면 **구조가 아니라 마감도를
측정**한다. 우리 자신의 R10 블라인드 A/B 가 공정했던 이유는 양쪽이 같은 마감
수준으로 지어졌기 때문이다. 1단계는 **R11 단독 이해도·탐색 테스트**로 한다.
비교는 마감이 대등해진 뒤에 별도 라운드로.

## 1. 대상 (6인)

| 유형 | 수 | 왜 |
|---|---|---|
| 문학 탐닉형 (연 20권+, 세계문학 관심) | 2 | 핵심 사용자 |
| 관심은 높지만 넓게 읽지 않은 독자 | 2 | 실제 성장 가능 사용자 |
| 3D 지도·게임에 익숙하지 않은 독자 | 2 | 조작 장벽 검출 |

모집 할당은 위 2·2·2 로 하되, **기록은 두 축으로 따로 적는다**:
`독서 [탐닉 / 관심]` × `3D [숙련 / 비숙련]`. 왜: 한 칸에 넣으라고 하면 3D 숙련
+ 문학 무관심 독자는 어느 칸에도 안 들어가고, 탐닉형이면서 3D 비숙련인 사람은
두 칸에 동시에 든다 — 단일 선택 칸은 채워지지 않거나 관찰자마다 다르게 채워진다.

**3D 비숙련 2석은 비율 추정용이 아니라 장벽 검출용이다.** 2인은 어떤 비율도
추정하지 못한다. 이 층은 **참가자별로 무엇에 막혔는지**를 서술로 보고하고,
"2인 중 n인" 형태로 집계하지 않는다.

제외: 이 프로젝트를 아는 사람, 개발 관여자.

## 2. 준비물

- 빌드: 커밋 고정 · `?lens=movement` 기본 · 개인 성좌 localStorage 초기화
- 화면 녹화 + 음성. 얼굴 녹화 불필요.
  녹화 파일은 **진행자 로컬 디스크에만** 보관하고, 1단계 보고서 확정 후 **30일
  이내 파기**한다. 참가자가 요청하면 즉시 파기한다.
- **진행자 1인 — 빌드를 만든 사람이 아니다.** 만든 사람은 진행도 배석도 하지
  않는다. 왜: 만든 사람 앞에서는 부정적인 말이 나오기 어렵고, 대본의 "제가 만든
  것"이라는 고지가 그 억제를 한 번 더 건다. 대본은 **"우리가 만든 것"**으로 읽는다.
- **코더 2 1인 — 빌드를 만든 사람이 아니고, 진행자의 기록지를 보지 않는다.**
  세션 후 녹화(화면+음성)와 회고 축어록만 보고 §4.1 의 판정 칸을 독립으로
  코딩한다. 왜: 기각 축인 '모델 형성'은 판정 칸이다. 설계자가 자기 설계를
  판정하는 칸을 실시간으로 혼자 코딩하면 §6 의 규율이 종이에서만 지켜진다.
  **불일치는 보수적으로 '아니오'로 세고, 불일치 건수를 결과와 함께 보고한다.**
- 기록지: **부록 C** (참가자 1인 1장). 코더 2 는 같은 판정 칸만 별지로 채운다.

## 3. 진행 (1인당 25–35분)

### 3.1 첫 60초 — 아무 말도 시키지 않는다

화면을 열고 **설명하지 않는다. think-aloud 를 요구하지 않는다.**
(발화를 요구하면 경외와 탐색이 동시에 망가진다. 회고는 뒤에 한다.)

관찰자는 시간만 기록한다:
- 첫 조작까지 걸린 시간
- 첫 조작의 종류 (회전 / 줌 / 클릭 / 패널 / 검색)
- 60초 안에 스스로 별을 하나라도 선택했는가

60초가 지나면 **"이게 무엇이라고 생각하세요?"**를 한 문장으로 받는다. 이것은
과제가 아니라 도입부다 — 카드 번호를 붙이지 않는다. (이 문장이 §4 '모델 형성'의
유일한 원자료다.)

### 3.2 과제 (순서 고정, 카드 1–4)

**시간 규칙**: 시간은 **카드를 건넨 순간부터 참가자가 답(이름 / 책 / 복귀 /
표시)을 말한 순간까지** 잰다. 막혔을 때의 60초 질문은 시계를 멈추지 않는다.
왜: 시작·종료가 정의되지 않으면 6장의 기록지가 서로 다른 것을 잰 뒤 같은 열에
쌓인다.

1. **카드 1 — 카프카와 관련 있지만 모르는 작가 한 명을 찾는다.**
   관찰: 사용한 경로를 **전부, 순서대로** 적는다 (원경 성좌선 / 중경 연결선 /
   검색 / 관측층 색인 / 카드의 관계 목록). 왜: "성좌선"은 원경의 별자리선과
   중경에서 뻗는 연결선을 같은 칸에 뭉갠다. 그 둘은 다른 화면의 다른 물건이다.
   **관측 렌즈**도 여기서 본다: 작가를 고르면 이웃이 끌려오고 원위치에 유령·궤적이
   남는데, 그것을 **언급하거나 따라가는가**.
2. **카드 2 — 그 작가의 입문작과 왜 그것부터 읽어야 하는지.**
   대상은 **미준비 작가**로 유도한다 — 궤도 경험만으로 답이 나오는지가 목적이다.
   **착륙 없이 완수했는가**가 기각 축('궤도 경험의 자족성')이다.
3. **카드 3 — 들어갈 수 있는 곳을 하나 찾아 들어가서 작품 하나를 보고, 처음
   있던 화면으로 돌아온다.**
   - **사실로 적어 둔다**: 착륙 가능 작가는 카프카·나쓰메 소세키·타고르 3인뿐이고,
     카프카에서 뻗는 관계 위에서 만나는 작가 중 착륙 가능은 카프카 하나다.
     따라서 **실질적으로 6인 전원이 같은 회랑(카프카)을 보고, 쉬는 권은 전원
     책등이며, 소장 차이는 당긴 권에서만 갈린다**(실물 초판 보유 권 = 진짜 표지,
     미보유 권 = 민무늬 장정). 이것은 표본이 아니라 상수다 — 회랑 4행의 결과를
     "여러 회랑에 대한 관찰"로 읽으면 안 된다.
   - 착륙 중, 복귀 전에 **한 가지만 묻는다**: "책들이 놓인 자리가 무엇을 말하는
     것 같으세요?" — R12-c 회랑의 네 채널(연도 축 — 바닥의 연도 각인과 균일 칸 ·
     입문 경로의 단 — 아랫단 = 입문 · 입문 순서의 민 숫자 · 소장 = 당긴 책의
     표지가 실물/민장정으로 갈림)이 **설명 없이** 읽히는지는 자동 계약이 잴 수
     없다. 계약은 렌더가 규칙대로임을 증명할 뿐, 규칙이 사람에게 도착하는지는
     여기서만 측정된다.
   - 복귀 직후 **한 번만** 묻는다: "지금 어디에 와 계신 것 같으세요?" — 열린
     질문이다. 왜: think-aloud 를 껐으므로 '원래 자리 인지'를 코딩할 관측 대상이
     달리 없다. "여기가 처음 화면 맞죠?"라고 물으면 답을 주게 된다.
4. **카드 4 — 읽은 적 있는 작가를 표시한다.**
   책이 아니라 **작가**다. UI 는 작가 단위로만 표시하고, 『변신』 하나 읽은
   사람에게 "이 작가를 읽었다"는 자기규정이 걸린다.
   표시 후에는 **"다음 독서"를 이름으로 가리키지 않는다** — 부록 A 의 "표시하고
   나서 화면에 달라진 게 있으면 읽어 주세요" 한 줄만 읽는다. 화면의 문자열
   이름을 진행자가 먼저 말하면 §6 "가리키지 않는다"의 말 버전이 되고, 참가자가
   '나의 성좌' 상자를 스스로 찾은 것인지 지시받은 것인지 구분할 수 없게 된다.

**자유 탐색 (카드 없음)** — 남은 5분은 과제 없이 자유 탐색. (이 구간의 행동이
가장 중요한 데이터다.)

### 3.3 회고 인터뷰 (5분)

부록 A 의 회고 문장과 **일대일로 대응한다.** 순서도 같다.

- 이 화면이 무엇을 하는 물건이라고 느꼈나
- 별의 크기·색이 무엇을 뜻한다고 생각했나 (**정답을 알려주지 않고** 추측을 듣는다)
- 파란(푸른) 별을 봤는가, 무엇이라고 생각했나
- 작가를 골랐을 때 주변 별들이 어떻게 됐다고 느꼈나 (자리가 바뀐 것 같았나,
  원래 거기 있던 것 같았나)
- 카프카와 그 작가를 잇는 선은 어느 쪽에서 어느 쪽으로 간다고 봤나
- (착륙을 본 참가자에게) 책을 당겼을 때 **진짜 표지가 나오는 권과 민무늬 장정
  그대로인 권**이 갈렸는데, 그 차이가 무엇일 것 같나 — "실물이 없어서"류의
  답이 나오는지, "오류/미완성"으로 읽히는지
- (착륙을 본 참가자에게) 바닥의 **세로 점선 뒤로 빈 칸들**이 있었는데,
  무엇이라고 생각했나 (후보 행 — 언급 없음도 데이터다)
- (착륙을 본 참가자에게) 몇몇 책 이름 앞의 **숫자(1, 2, 3)**는 무엇이라고
  생각했나
- 착륙할 수 없는 작가를 만났을 때 어떤 느낌이었나
- 다시 온다면 무엇을 하러 오겠나

## 4. 무엇을 관찰하는가 — "멋있다"는 데이터가 아니다

| 지표 | 측정 | 목표 |
|---|---|---|
| 모델 형성 | 60초 한 문장이 §4.1 (a) 를 만족하는가 | 6인 중 4인 이상 |
| 자발적 첫 행동 | 설명 없이 조작을 시작했는가 | 6인 중 5인 이상 |
| 관계 발견 | 카드 1 을 성좌·관계로 풀었는가 (§4.1 (b)) | 6인 중 3인 이상 |
| 궤도 경험의 자족성 | 카드 2 를 착륙 없이 완수했는가 | 6인 중 5인 이상 |
| 방향감 — 원경 복귀 | 카드 3 복귀 후 "하늘로 돌아왔다"고 인지하는가 | 6인 중 5인 이상 |
| 방향감 — 출발 구도 | 복귀 후 "처음 있던 그 자리"라고 인지하는가 (예/아니오/판단 불가) | **기록만** — 목표 과반 (홈 복원 수리 직후 첫 측정) |
| 미준비의 정직함 | 회고가 §4.1 (d) 의 어느 코드인가 | "속았다/빈약" 2인 이하 |
| 중경의 왜곡 가시성 | 이웃이 "끌려왔다/모였다"로 읽히고 원위치 흔적(유령·궤적)을 인지하는가 | **기록만** — 기준선 |
| 회랑의 연도 축 | 착륙 중 질문의 답에 시간·연도·순서 개념이 있는가 (바닥의 연도 각인·균일 칸) | **기록만** — 목표 착륙 참가자 과반 |
| 입문 경로의 단 | 같은 답에 아랫단/윗단이 "먼저 읽을 것 / 그 밖"으로 갈린다는 개념이 있는가 | **기록만** — 목표 과반 |
| 소장의 정직성 | 회고에서 당긴 책의 민무늬 장정을 "실물이 없어서"로 해석하는가 ("오류/미완성" 아님) | **기록만** — 목표 과반 |
| 입문 순서 숫자 | 회고에서 이름 앞 숫자(1 2 3)를 입문·추천 순서로 해석하는가 | **기록만** — 목표 과반 |
| 사망선 뒤 빈 칸 | 바닥의 세로 점선 뒤 빈 칸을 어떻게 읽는가 (§4.1 (f)) | **기록만** — 후보 행, 문턱 없음 |
| 이륙의 자발 발견 | 회랑에서 이름 뜬 별을 눌러 이륙하는 것을 스스로 발견하는가 (§4.1 (g) ①과 연결) | **기록만** — 후보 행, 문턱 없음 |

**목표 열은 통과 문턱이 아니다.** 논문 §⑩ 통합 조건에 대응하는 목표치이고,
통과·실패 판정은 이 프로토콜이 아니라 **§⑩ 과 대조해 CTO 가** 내리고 결정
로그에 사후 기록한다(게이트 축소, CPO 2026-08-25 — 통합 직전 최종 15분만 CPO).
사전 등록된 기각 조건은 아래 두 개뿐이며, 나머지 행은 어느 쪽으로 떨어져도
자동으로 아무 일도 일으키지 않는다.

행별 대응: 모델 형성 · 자발적 첫 행동 · 중경의 왜곡 가시성 → §⑩ 조건 1(첫
진입과 중경이 이해됨); 회랑 4행(연도 축·단·소장·숫자) → 조건 2(착륙 품질);
미준비의 정직함 → 조건 3(플레이스홀더로 보이지 않음); 방향감 2행 → 조건
4(방향감 상실 없음). 후보 2행(사망선·이륙)은 어느 조건에도 걸리지 않는다.

회랑 4행과 중경 1행은 이 라운드에서 처음 측정되는 문법이므로 **1단계에서는 기각 축이
아니다** — 첫 측정은 기준선이고, 기각 축 승격은 결과를 보고 CPO 가 판정한다(중경
수치 계약을 회귀 방지 수준에 묶은 것과 같은 이유: 처음 재는 지각 성공을 문턱으로
확정하지 않는다). 이 유예는 **다음 라운드의 승격 규칙**이지, 이번 라운드의 결과를
보고 문턱을 정하겠다는 뜻이 아니다.

**한 가지 결과는 미리 등록해 둔다 (기각이 아니라 주장의 강등)**: 착륙 참가자
중 '소장의 정직성'을 "실물이 없어서"로 읽은 사람이 **절반 미만**이면, 논문 §③/§⑦
의 "소장 여부는 **당김의 순간에** 드러난다"는 문장을 **미검증으로 강등**한다.
왜: 번들 README 가 리뷰어에게 "네 채널이 설명 없이 읽히는가"를 첫 질문으로
내밀면서, 그 답이 부정일 때 논문의 단정이 그대로 남으면 회랑은 자기 README
로부터 보호받는 셈이 된다. 기록만인 행도 **주장에 대해서는** 결과를 낸다.

### 욕망 행 — 행동 4종 (자유 탐색 구간, CPO 비준 2026-08-24)

"멋있다"는 데이터가 아니지만 **욕망은 데이터다** — 발화가 아니라 행동으로 잰다.
네 행 모두 **과제 카드가 없는 자유 탐색 구간**에서만 센다(과제 중의 같은 행동은
지시된 것이라 세지 않는다). 코딩 규칙은 §4.1 (g).

| 행동 | 무엇을 세는가 | 이 라운드(6인)의 지위 |
|---|---|---|
| ① 두 번째 작가 자발 선택 | 카드 없이 **다른** 작가를 스스로 골라 카드를 열었는가 | 기록·보고 — 목표 과반 |
| ② 관계선 자발 추적 | 선·관계 목록을 따라 이웃으로 **이동**했는가(바라보기만은 아니오) | 기록·보고 — 목표 과반 |
| ③ 작품 자발 진입 | 회랑의 책·작품 목록을 스스로 열었는가 | 기록·보고 — 목표 과반 |
| ④ 기억한 발견 | 회고에서 과제 밖의 것을 **이름·내용으로** 말했는가 | 기록·보고 — 목표 과반 |

6인 라운드에서 네 행은 기각 축이 아니다(행의 첫 측정은 기준선이라는 §4 의 원칙과
같다). **기각 축으로 쓰이는 곳은 §7 의 0단계 3인 테스트**이고, 그 조건은 거기에
미리 등록돼 있다. 다섯째 행동 **재방문**은 한 세션에서 잴 수 없으므로(추적 없음 —
두 번째 만남에서만 관찰된다) §5 에 남는다.

### 기록·보고 지표 — 판정에 쓰지 않는다

| 지표 | 왜 판정에 쓰지 않는가 |
|---|---|
| 경외 발화("멋있다", 감탄, 첫인상 강도) | 프로토타입 마감도가 교란 변수이고, 발화는 행동보다 진행자 효과에 약하다. 욕망은 위 행동 4종이 잰다 |
| 자발적 잔류 시간 | 자유 탐색 구간은 그대로 두고 **시간과 행동만 기록**하되 기각에 쓰지 않는다 |

두 지표는 **기록하고 보고한다.** 유예는 "재지 않는다"가 아니라 "판정에 쓰지
않는다"이다 — 이 구분을 지우면 나중에 비교할 기준선이 남지 않는다. (CPO 비준
2026-08-24: 판정은 행동 4종, 발화·시간은 기록.)

**기각 조건 (1단계, 이해도·탐색에 한정)**: 모델 형성이 6인 중 2인 이하면 원경
설계를 다시 한다. 궤도 경험의 자족성(카드 2)이 6인 중 2인 이하면 궤도 아카이브를
다시 설계한다. **경외·잔류로는 아무것도 기각하지 않는다.**

**6인 결과는 신호지 입증이 아니다.** n=6 에서 4/6 은 **절반에게 통하는 빌드와
7할에게 통하는 빌드를 구분하지 못한다**(참값 0.5 일 때 4인 이상이 나올 확률
0.344, 참값 0.4 일 때도 0.179). 5/6 목표는 참값 0.7 인 빌드를 열 번 중 여섯 번
놓친다(≥5 확률 0.420). 따라서 목표 미달은 "빌드가 실패했다"가 아니라 "이 표본이
말해 줄 수 있는 범위 밖"이다. 기각 조건과 목표 사이의 결과(예: 모델 형성 3/6,
자족성 3–4/6)는 **통과도 기각도 아니다** — §⑩ 의 통합 금지 상태가 그대로
유지되고, **재관찰인지 재설계인지는 CTO 가 판정해 사후 기록한다.** 이 대역에서 사후에
문턱을 옮기지 않는다. 3D 비숙련 2석은 **장벽 검출용**이므로 참가자별 서술로
보고하고 비율로 집계하지 않는다.

### 4.1 판정 규칙 — 판정 칸의 코딩 사전

판정 칸은 관찰자의 인상이 아니라 **규칙**으로 채운다. 규칙을 데이터 본 뒤에
쓰면 §6 의 규율이 무의미해지므로 여기 미리 고정한다. 진행자와 코더 2 는 같은
규칙을 쓰고, **불일치는 '아니오'로 센다**(보수적).

**(a) 모델 형성** — 60초 한 문장이 다음 중 하나면 `예`:
- **영역을 지목한다**: 작가 · 작품 · 책 · 소설 · 문학 (및 동의어)
- **사물 사이의 관계를 지목한다**: 관계 · 연결 · 계보 · 영향 · 지도 · 성좌를
  **"무엇의"** 관계인지와 함께 (예: "작가들 사이의 관계")

시각 은유만 있으면 `아니오`: "우주", "하늘", "별", "별자리"에 지시 대상이 붙지
않은 문장. 애매하면 `아니오`. 왜: 이 칸은 기각 축이다. 관대하게 세면 기각이
일어나지 않는다.

**(b) 관계 발견** — 기록지의 경로 칸은 **순서 있는 다중 선택**이다("사용한 경로
전부, 순서대로"). `예` 는 **모르는 작가를 실제로 드러낸 마지막 단계**가
`원경 성좌선` 또는 `중경 연결선` 또는 `카드의 관계 목록`일 때만.
`관측층 색인` 또는 `검색`이 그 단계면 `아니오`. 단, **카프카를 출발점으로 찾기
위해 쓴 검색은 실격 사유가 아니다** — 우회로 세는 것은 관계 대신 검색으로 답에
도달한 경우다. 관계의 **종류**(번역·영향 등)를 확인했는지는 별도 칸에 어디서
확인했는지와 함께 적는다.

**(c) 방향감** — 두 칸을 따로 코딩한다.
- `원경 복귀 인지` = `예`: 복귀 직후 **추가 회전·줌·검색 없이** 완료를 표시한다
  (말 또는 손 떼기). 복귀 후에도 찾기 조작을 계속하거나 "여기 맞나요?"류의 질문을
  하면 `아니오`.
- `출발 구도 인지` = 복귀 직후 열린 질문("지금 어디에 와 계신 것 같으세요?")의
  답으로 코딩한다. "처음 그 자리"류 = `예`, "돌아오긴 했는데 어딘지 모르겠다"류
  = `아니오`, 답이 위치를 말하지 않으면 `판단 불가`.
- 관찰자는 **사실 하나**를 따로 적는다: 복귀 후 출발 별(카프카)이 화면 안에
  있었는가. 왜: 이 사실이 없으면 사람의 방향감과 홈 복원 동작을 나중에 분리할 수
  없다.

**(d) 미준비의 정직함** — 착륙 불가 작가 소감을 셋 중 하나로 코딩한다.
- `속았다·빈약` : 닫힌 착륙을 **제품의 결함**으로 귀속 (오류 · 미완성 · 속았다 ·
  빈약 등) → 부정으로 센다
- `아직 없다·준비 중` : 아직 만들어지지 않은 것으로 읽음 → 부정 아님
- `데모·미완성 제품으로 읽음` : "카프카만 되면 데모 아닌가", "언제 열리는지
  안 쓰여 있다" → **부정으로 세지 않되 따로 집계한다.** 왜: 이것은 정직함의
  실패가 아니라 **기대 관리의 공백**이고, 고치는 방법이 다르다(문구 대 자산).
- 중립·무응답 : 부정 아님

또한 **착륙을 시도한 미준비 작가의 이름**을 적는다 — 자산 우선순위 자료다.

**(e) 착륙 참가자** — 카드 3 의 `성공[ ]` 이 체크된 참가자. 회랑 4행의 분모는
6이 아니라 이 수다. 소장의 정직성 행은 그중에서도 **책을 당긴** 참가자만
분모로 센다 — 소장은 당김의 순간에만 갈리므로, 당기지 않은 사람은 그 채널을
본 적이 없다(카드 3 을 완수했으면 당긴 것이다 — 작품은 당겨서 본다).

**(f) 회랑 4행 + 후보 2행** — 착륙 중 질문의 답과 회고 답을 서브코드로 나눈다.
- 연도 축: `시간·연도·순서 개념 [예/아니오]`
- 입문 경로의 단: `아랫단·윗단 = 먼저 읽을 것 / 그 밖 [예/아니오]`,
  `단 차이 언급 [예/아니오]`
- 소장의 정직성: `[실물 없음 / 순서 밖·덜 중요 / 오류·미완성 / 모름]` +
  **근거** `[당긴 책의 표지 차이 / 카드의 '초판' 표 / 추측]`. 왜: "실물 없음"에
  도달하는 경로가 당김의 순간(진짜 표지 대 민장정)인지 카드의 표 부재인지에
  따라 고칠 곳이 다르다.
- 입문 순서 숫자: `[입문·추천 순서 / 범례의 ①②③와 혼동 / 연도 순 / 모름]` +
  `범례 ①②③와 혼동한 순간이 있었는가 [예/아니오]`.
  회랑의 쪽지는 **민 숫자 "1 2 3"**을 나르고, 동그라미 숫자 ①②③는 **하늘과
  범례의 관측층 색인**에만 남는다. 혼동 건수는 이 분리가 충분한지를 CPO 가
  판정할 자료다 — `아니오`가 곧 채널 실패는 아니고, "다른 뜻으로 읽었다"와
  "못 봤다"를 섞으면 무엇을 고칠지 알 수 없다.
- 사망선 뒤 빈 칸 (후보 행): `[의미를 읽음(발화 그대로) / 오류·미완성으로 읽음 /
  언급 없음]`. 빈 칸은 빈 채로 두는 설계이므로 `언급 없음`은 실패가 아니다 —
  이 행이 재는 것은 세로 점선이 침묵을 설명하는가이지, 참가자가 반드시
  말하는가가 아니다.
- 이륙의 자발 발견 (후보 행): `[스스로 발견 / 60초 질문 뒤 / 하지 않음]` —
  회랑에서 이름 뜬 별을 눌러 그 자리에서 날아오른 경우만. 이 경로로 다른
  작가의 카드가 열리면 §4.1 (g) ① 로도 센다(욕망이 잰다, 경로가 아니다).

**(g) 욕망 행동 4종** — 자유 탐색 구간(카드 없음)에서만 센다. 과제 중 같은
행동은 `아니오`. 진행자의 60초 질문("지금 무엇을 찾고 계세요?") 뒤에 일어난
행동은 `질문 뒤`로 따로 적고 `예`로 세지 않는다.
- ① 두 번째 작가 자발 선택 = `예`: 과제에서 다룬 작가(카프카 · 카드 1 의 작가)가
  **아닌** 작가의 카드를 스스로 열었다. 검색으로 열어도 `예`(욕망이 잰다, 경로가
  아니다). 회랑에서 이름 뜬 별을 눌러 이륙해 연 것도 `예` — 그 경우 (f) 의
  '이륙의 자발 발견'에도 적는다. 호버만은 `아니오`.
- ② 관계선 자발 추적 = `예`: 선 또는 카드의 관계 목록을 **따라 이동**해 이웃의
  카드가 열렸다. 선을 바라보거나 언급만 하면 `아니오`. 출발점이 어느 작가든 상관없다.
- ③ 작품 자발 진입 = `예`: 회랑의 책(당김) 또는 카드·착륙 패널의 작품 항목을
  스스로 열어 그 작품의 문장이 화면에 나왔다. 카드 3 에서 본 작품을 자유 탐색에서
  다시 열면 `예`(반복도 욕망이다).
- ④ 기억한 발견 = `예`: 회고("무엇을 하는 물건", "다시 온다면") 어디서든 과제 카드에
  없던 것을 **작가·작품·관계의 이름이나 내용으로** 말했다. "별이 많았다"류의
  시각 인상은 `아니오`. 기록지에 발화를 그대로 옮긴다.
- 각 행은 **횟수가 아니라 예/아니오**다. 횟수는 자발 행동 칸에 서술로 남긴다.

## 5. 2단계 — 개인 성좌의 재방문 가설 (7일) · **보류**

> **CPO 판정 (2026-08-20)**: 재방문 가설의 기각 조건도 최소 시각 목표 슬라이스
> 완성 이후로 미룬다. 아래 설계는 그때 쓰기 위해 보존한다.

경외는 한 세션에서 볼 수 있지만 **재방문은 시간 없이 검증할 수 없다.**

- 대상: 1단계 참가자 중 동의자 + 필요 시 보충 (총 10–12인)
- 절차: 첫날 읽은 작가 5명 이상 표시 → 개인 성좌 저장 → 7일
- 계측: **연구용 빌드에서 명시적 동의를 받고 로컬 이벤트 로그만** 기록.
  서버 전송 없음. 7일 후 참가자가 직접 내보내 제출한다.
  (이 절차는 개정안 ①이 정의하려는 경계 안에 있다 — 로컬 상태, 자발적 제출)
- 재방문 알림: 보내지 않거나, 전원에게 동일하게 **한 번만**
- **기각 조건**: 자발적 재방문이 **표본의 1/6 이하**(10–12인 기준 0–2명)이면
  "개인 성좌 = 재방문 동력"이라는 강한 주장을 기각한다. **절반 이상**(10–12인
  기준 5–6명 이상)이 돌아와 성좌를 확장하면 다음 규모의 실험을 할 신호는 되지만
  **입증은 아니다.** (원래 6인 코호트의 비율을 그대로 옮긴 것이다 — 새 문턱을
  만든 것이 아니다. 2단계 활성화 시 CPO 가 표본 크기를 확정한다.)

## 6. 진행자 규율 (R9 에서 값을 치른 것)

- **가리키지 않는다.** 검색창·버튼을 손으로 지시하면 발견성을 제조하게 된다.
  R9 에서 QA 자동 스크롤이 정확히 그 일을 했고, 그것이 실패를 통과로 만들었다.
  화면의 문자열 이름을 먼저 말하는 것도 같은 위반이다.
- 참가자가 막히면 60초 기다린 뒤 **"지금 무엇을 찾고 계세요?"**만 묻는다.
- 기능을 설명하지 않는다. 설명해야 이해되는 것은 이해되지 않은 것이다.
- **의미를 확인하는 질문에 맞다/아니다를 말하지 않는다.** "선으로 이어진 사람들이
  관련 있다는 거죠?"는 기능 질문이 아니라 §4 '관계 발견'의 답이다. 되묻는다:
  "그렇게 보이세요? 왜 그렇게 보이세요?" 그리고 발화를 그대로 기록지에 옮긴다.
- 관찰자의 해석은 기록지의 **별도 칸**에 쓴다. 행동 기록과 섞지 않는다.
- **진행자는 빌드를 만든 사람이 아니고, 판정 칸은 두 사람이 코딩한다.**
  코더 2 는 진행자의 기록지를 보지 않고 녹화와 축어록만으로 §4.1 을 적용한다.
  불일치는 '아니오'로 세고 건수를 보고한다. 왜: 종이 위에서 해석과 행동을
  나누는 것은 **코더와 설계자를 나누지 않는다.**
- 대본을 벗어나 설명하기 시작하면 그 세션의 데이터는 버린다.

## 7. 0단계 — 카프카 골든 저니 3인 비공식 욕망 테스트 (CPO 비준 2026-08-24)

이 라운드는 6인 관찰보다 **먼저** 열리고, 6인 관찰을 여는 조건이다(테제 §⑩ 조건
2 의 2단). 짧고 비공식이지만 **기각 조건은 미리 등록한다** — 비공식은 절차의
가벼움이지 판정의 가벼움이 아니다.

- **무엇을 보여주는가**: R12 카프카 골든 저니 빌드(커밋 고정). CPO 의 15분 판정을
  통과한 뒤의 빌드다 — 3인은 CPO 가 이미 "볼 가치가 있다"고 한 것을 본다.
- **대상 3인**: 이 프로젝트를 모르는 독자. 독서 축만 기록(`탐닉 / 관심`). **0단계
  참가자는 1단계(6인)에 다시 오지 않는다**(빌드를 이미 봤으므로).
- **진행 (1인당 15분)**: §3.1 첫 60초 규칙 그대로(설명 없음, think-aloud 없음) →
  **과제 카드 없이 자유 탐색 10분** → 회고 3문항("무엇을 하는 물건" · "기억에 남은
  작가나 책이나 연결" · "다시 온다면 무엇을 하러"). 진행자≠만든 사람 · 손은 책상
  아래 · §6 규율 전부 적용. 코더 2 는 두지 않는다(기록 행이 행동 4종뿐이고 녹화로
  재확인한다).
- **기록**: 부록 C 의 [자유 탐색] 블록만 쓴다 — 행동 4종(§4.1 (g)) + 시간 + 경외
  발화 그대로.
- **사전 등록 기각 조건 (유일)**: **3인 중 0인이 ①(두 번째 작가 자발 선택)과
  ③(작품 자발 진입) 어느 것도 하지 않으면 골든 저니 불통과** — 연출을 다시 한다.
  1인이라도 ① 또는 ③을 하면 통과이고, 나머지 행은 기록·보고다. 왜 0/3 인가:
  3인은 비율을 추정하지 못하고 "아무도 하지 않았다"만 말할 수 있다. 그 문턱을
  여기서 높이면 판정이 CTO 의 취향이 된다 — 숫자는 CPO 가 바꾼다.
- **결과 보고**: 참가자별 서술 3건 + 행동 4종 표 + 기각 조건 판정 한 줄. 비율로
  집계하지 않는다.

## 부록 B — 과제 카드 (한 장씩 건넨다)

카드에는 **목표만** 쓰고 경로를 쓰지 않는다.

1. 카프카와 관련이 있지만 **모르는 작가**를 한 명 찾아 주세요.
2. 그 작가의 책 중 **가장 먼저 읽어야 할 책**과 **왜 그 책부터인지**를 찾아 주세요.
3. **들어갈 수 있는 곳**을 하나 찾아 들어가서 작품 하나를 보고, **처음 있던
   화면으로** 돌아와 주세요.
4. 읽으신 적 있는 **작가**가 있으면 **표시**해 보세요.

카드 2 의 대상은 **자산이 준비되지 않은 작가**로 유도한다(예: 카프카의 관계
목록에는 있으나 착륙지가 없는 작가). 유도는 카드 문구가 아니라 **카드 1 의
출발점 선택**으로 한다 — "들어갈 수 없는 곳"을 지목해 보여주지 않는다.

카드 3 이 "아무 곳이나"가 아닌 이유: 착륙 가능 작가는 3인뿐이고 카프카 경로에는
카프카 하나뿐이다. "아무 곳이나"라고 쓰면 참가자는 미준비 문구만 만나고 진행자가
가리키게 된다(§6 위반). 대신 **착륙지를 어떻게 찾았는지**를 기록한다.

## 부록 E — 합성 드라이런(2026-08-21)이 남긴 것

사람 라운드 전에 **합성 드라이런**을 한 번 돌렸다. LLM 페르소나 4인이 이 대본과
과제 카드만 들고 실제 빌드를 조작했다. **여기서 나온 것은 §4 의 어느 행에도
숫자를 주지 않고, 통과·기각을 판정하지 않는다.** 합성 참가자는 한국어 UI 문자열을
한 글자도 놓치지 않고 읽고, 피로·시력·작은 글씨의 부담을 흉내만 내며, 어포던스를
사람보다 훨씬 체계적으로 추론하고, 스크린샷 단위로 행동하므로 시간·망설임·마우스
배회·첫 조작까지의 초를 전혀 제공하지 않는다. 네 세션이 같은 해석에 수렴한 것도
사람 간 합의가 아니라 같은 모델 계열이 같은 화면을 읽은 결과일 수 있다. 또한
"본 것을 말하지 않는" 사람 특유의 침묵을 이 방법은 전혀 포착하지 못한다. 이
드라이런이 확실히 준 것은 셋뿐이다: **기록지와 카드의 구멍**(이 개정이 메웠다),
**누가 눌러도 같은 결과가 나오는 빌드의 동작**(소스와 재현으로 확정, 별도 수리),
그리고 아래의 **물어볼 가치가 있는 질문 목록**.

아래는 결과가 아니라 **가설**이다. 사람 라운드에서 각 행·프로브로 답한다.

- **H1. 선의 방향과 종류는 선에서 읽히지 않는가?** 합성 4인 전원이 "관련
  있다"까지는 즉시 읽었으나 영향의 방향은 아무도 읽지 못했다.
  → §4 '관계 발견' 행 + 회고의 "선은 어느 쪽에서 어느 쪽으로" 질문 + 의미 확인
  질문 기록.
- **H2. 책등 정면의 "실물 없음" 해석은 서가가 아니라 카드의 '초판' 표 부재에서
  오는가?** 합성 3/4 가 "목록에서 이 책만 초판 딱지가 없다"는 경로로 도달했고,
  서가만 봤을 때의 1차 반응은 "고장"·"덜 중요"였다.
  → §4 '소장의 정직성' 행의 **근거** 서브코드 [서가 자체 / 카드의 '초판' 표 /
  추측].
- **H3. 숫자 채널의 충돌은 사람에게서 더 오래 가는가?** 합성 4/4 가 스스로
  알아채고 정정했다 — 사람은 더 느릴 수 있고, 서가 쪽지가 민 숫자로 바뀐 뒤에는
  다른 형태로 남을 수 있다.
  → §4 '입문 순서 숫자' 행의 `범례의 ①②③와 혼동` 코드와 혼동 순간 칸.
- **H4. 앞줄/뒷줄은 "중요/덜 중요"로, 위로 뜬 책은 "다른 종류/순서 밖"으로
  읽히는가?** 합성 4/4 가 x축=연도는 즉시 읽었지만(눈금이 사실상 답을 준다)
  "입문 경로 앞단"이라는 의도에는 2인만 근접했다.
  → 착륙 중 질문 + §4 '입문 경로의 단' 행 + 높이 언급 코드.
- **H5. '미준비'는 "속았다"가 아니라 "데모인가 / 언제 열리나"로 읽히는가?**
  합성 4/4 가 "공사 중 팻말"로 읽었고 분노는 0이었으나, 2/4 가 "언제 열리는지
  없다", 1/4 가 "카프카만 되면 데모"라고 했다.
  → §4 '미준비의 정직함' 행의 3분 코드 중 `데모·미완성 제품으로 읽음`.
- **H6. 별 크기는 유명세로 통하고, 색은 범례 없이는 읽히지 않으며, 파란 별은
  아무에게도 설명되지 않는가?** 합성 4/4 가 크기=유명세, 색은 슬라이더를 만져
  범례를 읽은 3인만 "활동기", 파란 별은 4/4 가 몰랐다.
  → 회고의 크기·색 질문 + 파란 별 프로브 + `슬라이더를 만졌는가 / 범례를
  읽었다고 말했는가` 층화 코드.
