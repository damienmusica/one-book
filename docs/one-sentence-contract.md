# 한 문장 계약 — 이 제품의 상급 게이트 (2026-08-30, CPO 전면 수용)

> **"다음 읽을 책을 못 고르는 독자가 15분 안에 '읽고 싶다' 하나를 담고,
> 일주일 뒤 스스로 돌아온다."**

이 문장이 모든 라운드의 상급 게이트다. 아름다움·우주론·정합성·계약 수는
이 문장에 봉사할 때만 가치가 있다. 근거와 전문(前文)은 사후 부검
`vault: reference/lp-postmortem-verdict-2026-08-30.md` — 그 판결을 CPO가
전면 수용하면서 이 문서가 발효됐다.

## 성과 지표 (게이트 위에 서는 것)

| 지표 | 정의 | 측정 |
|---|---|---|
| 첫 담기 시간 | 콜드 로드 → 첫 '읽고 싶음' 표시까지 중앙값 | 낯선-눈 세션 녹화 + `lp.metrics.*` 로컬 타임스탬프 |
| 과제 완수율 | "읽고 싶은 책 하나 담기" 성공 비율 | 낯선-눈 세션 |
| 자발 재방문 | 일주일 뒤 링크 재발송 없이 돌아온 수 | 참가자 추적 |

성과 지표를 움직이지 않은 라운드는 게이트가 전부 초록이어도 **미완**이다.
(인프라 라운드는 사전에 인프라로 명시했을 때만 예외.)

## 동결 (판결 §5, 발효 중)

- **UX 입법 동결**: 3안 비교(아래)의 판정 전까지 3D 관측선(A안)의 상호작용
  법을 새로 만들거나 고치지 않는다. 상호작용-법 PR은 대안 비교 문서 링크
  없이는 CI 가 막는다.
- **UX 계약 신설 동결**: 검증된 문법에만 계약을 단다. 데이터 층 계약·기존
  계약의 유지 보수는 예외.
- **속도 상한**: UX 라운드 주 1회 이하. 남는 실행력은 콘텐츠와 유통 표면으로.

## 3안 비교 (은유는 전제가 아니라 변수다)

같은 여정 — 시작 → 작가 발견 → 관계 홉 → 둘째 작가 → **읽고 싶은 책 담기** —
을 세 형태로 세우고, 낯선 5인이 과제로 비교한다. **지는 안은 A(3D)라도 죽인다.**

| 안 | 형태 | 입구 |
|---|---|---|
| A | 3D 관측선 (현행 성계) | `/` |
| B | 2D 성좌도 — 팬/줌 지도, 비행 없음 | `/chart.html` |
| C | 성좌 산책 — 자유항법 0, 인도된 홉 | `/walk/` |

대조군: 나무위키+서점 페이지로 같은 과제. 절차는 `docs/stranger-test-kit.md`.

## 손 떼기 조건 (판결 §6 — CPO 수용으로 발효)

1. 3안 비교에서 5인 중 4인+ 가 무비행(B/C)을 선호하고 A의 과제 시간이 2배
   이상 열세 → 3D 성계 제품 종료(데이터·큐레이션 존속).
2. 설계 대안 2세트 소진 후에도 4/5+ 과제 실패 또는 10분 내 이탈 → 탐험형
   문학 발견 전제 기각.
3. 자발 재방문 0/5 × 2회 연속 → 장난감 판정, 종료.
4. 심층 커버리지 재설계 후에도 4주 내 50% 미달 → 전제 붕괴, 종료.
   (2026-08-30 기준선: 정적 심층 표면 100/100 — 이 조건은 발효 즉시 충족)
5. 나무위키 대조군에 시간·만족 모두 열세 + 재선택 0/5 → 종료.
6. CPO 자발 접속 4주 연속 0회 → 종료.
7. 성계 탓에 본체 세션 4주 연속 0 → 성계 동결.

## 정직성의 위치 (개정)

**"지어내지 않는다"는 불변이다. "실물 없이는 깊이 없다"는 폐기한다.**
심층 경험의 재료는 우리가 이미 소유한 것 — 큐레이션 산문(importanceReason·
significance·관계 요약·입문 순서·난도), 자체 번역, 여는 문장 — 이고, 실물
자산(육필·초판·기록 사진)은 관문이 아니라 **보석**이다: 있으면 얹는다.
착륙(3D 회랑)의 실물 게이트는 유지하되, 심층은 착륙만이 아니다.
