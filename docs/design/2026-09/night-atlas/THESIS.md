# 밤의 도감 — night-atlas

**테제.** 어두운 띠는 장정 천이고 밝은 띠는 본문지다. 책 한 권의 물성 — 천·형압·금박·가름끈·꽃천 — 을 화면의 문법으로 옮긴다.
작가의 원어 이름은 천에 눌러 찍은 **형압**(유령 활자)으로 띠 전체를 채우고, **금은 손이 닿은 자리에만** 든다: 작가의 손(실제 서명)과 독자의 손(문·표시).
시스템이 쓰는 금은 한 화면에 두 번 이하이고, 그 이상은 독자가 표시할 때만 늘어난다 — 「관심 있는 책」을 누르면 단추가 금박이 되고 표지 위로 가름끈이 내려온다.

**타이포 사다리** (Noto Serif KR 400·600 하나로, 375→1280px)
- 유령 이름 126→274px(라틴, 단어마다 한 줄) · 한자·가나는 세로쓰기로 띠 높이를 채움(최대 432px) — 컨테이너 단위(cqw/cqh)로 글자 수에서 계산
- 작품 제목 74→168 · 작가 이름 44→104 · 절 제목 27→38 · 리드 18→21 · 본문 16 · 주석 13.4 · 라벨 11.5(자간 .22em, 600 — 한글의 스몰캡스 자리)
- 이름:본문 = 6.5:1 (지금 1.7:1). 밤 위에서 가장 밝은 값(`--cream`)은 이름과 표시 장치 둘뿐, 본문은 한 단계 아래(`--text`).

**팔레트 토큰**
- 밤: `--cloth`(쪽마다 다름) `--cloth-hi`(형압) `--cloth-lo`(발) · 집의 천 먹남색 `#21272c` / `#2c343b` / `#0e1013` — 근접-검정 `#14100a`(L .17)을 L .25~.29로 올림
- 밤 위 글자: `--cream #f4ecd8` `--text #d3c9b6` `--dim #aaa190` `--faint #989183` (집의 천 대비 12.8 / 9.2 / 5.9 / 4.8)
- 종이: `--paper #ebe2cd` `--paper-hi #f4eddd` `--paper-lo #dcd2ba` · 잉크 `--ink #2a2117` `--ink-2 #5c5143` `--ink-3 #6f6456` (12.3 / 6.0 / 4.5)
- 금박: `--gilt #d1ac5a` `-hi #e2c57c` `-lo #b08a3a` `--gilt-ink #1e1a12`. 테두리 상자·점선 괘선 0개. 질감은 인라인 SVG feTurbulence 한 장(주기 무늬는 축소 시 물결이 져서 버림).

**작가별 변수 — 전부 이미 가진 데이터에서 결정론적으로 (`build.py`의 `ghost()` `cloth()` `sign()`)**
1. 유령 이름 = `names.original`. 조판 방향은 문자에서: 한자·가나 → 세로쓰기, 아랍·히브리 → RTL, 그 밖 → 단어마다 한 줄(3줄 초과는 짧은 이웃끼리 합침). 크기 = 띠 폭 ÷ 가장 긴 단어.
2. 천 색 = `regions[0]` × `periods[0]`. 색상은 23개 권역을 서→동으로 세운 색상환(중부유럽 = 프러시안 청록 215°, 『변신』 초판 판지의 색; 이웃 권역은 이웃 색) — 문화적 색 상징을 쓰지 않는다. 명도는 시대: 고대가 가장 깊은 밤(L .248), 동시대가 새벽 직전(L .288). OKLCH C .03 고정. 카프카 `#142a30`, 무라사키·굴원 `#2e1b1d`.
3. 금박 서명 = `art/manifest.json`에 실물이 있을 때만(62/1,806: 카프카는 marks/ 에만, 무라사키·굴원은 없음). 천 위에서는 금박, 종이 위에서는 잉크. 없으면 아무것도 세우지 않고 금은 문(「여기서 읽기 시작」)으로 간다.
4. 깊이 = 잉크 상태. 도판은 눌러 찍은 형압, 스케치는 **윤곽선뿐인 이름 + 빗금 친 천 + 점선 라벨 「스케치 — 아직 출처에 대보지 않은 쪽」**(고지도의 미측량 지역). 색인에서는 밝기가 곧 검증의 깊이: ● 크림·600 / ○ 한 단계 어둡게 / ◌ 점선.
5. 표지 자리 = 초판 실물 사진이 있으면 그것(11점), 없으면 천 조각에 `titleOriginal`만 찍은 표제 카드 — 표지인 척하지 않는다.

**일곱 과제** ① 위 1~5 ② 위 사다리 ③ 표시 장치: 335×60px(모바일 첫 화면 y=303, 지금 77×25px) 크림 라벨 → 누르면 금박+가름끈+「서재에 꽂혔다」, 나머지 세 칸은 사다리, 모바일은 장치가 화면 밖으로 나가면 바닥 바가 따라옴 ④ 문: 첫 장 맨 위 y=121(지금 y=1071), 없는 이름에는 「아직 이 책에 없는 이름이다」 ⑤ 판본: 한국어/원서로 묶은 표(출판사·옮긴이·연도·판정·ISBN·나가는 문) + 옮긴이 열 아래 근거 문장, 모바일은 같은 마크업이 블록으로 접힘 ⑥ 위 4 ⑦ 375·1280 실측, 가로 넘침 0, 콘솔 오류 0, 제3자 요청 0.

**위험**
- 목업의 한자·키릴은 Noto Serif KR, 그리스·아랍·데바나가리는 시스템 폴백이다. 출시하려면 Noto Serif JP/SC·Noto Naskh Arabic·Noto Serif Devanagari/Bengali(전부 OFL)를 유령 이름·원어명 글리프만 서브셋으로 자체 호스팅해야 밤의 질감이 기기마다 같다.
- 컨테이너 쿼리 단위(cqw/cqh)에 기댄다 — Safari 16 / Chrome 105 미만에서는 유령 이름이 기본 크기로 떨어진다(내용은 안 깨짐).
- 같은 권역·같은 시대의 작가는 같은 천을 입는다(무라사키 = 굴원). 개체 구별은 유령 이름이 지고, 천은 "어느 서가인가"만 말한다 — 의도지만 1,806쪽을 넘겨 보며 검증해야 한다.
- 교대 띠는 쪽을 길게 만든다(카프카 쪽 1280px에서 4,500px). 글자 예산은 그대로이고 늘어난 것은 여백과 표지다.
- 표시 확인 문구·판본 표의 열 이름·「활동」 열 머리는 새 UI 라벨이다(작가 산문은 한 글자도 새로 쓰지 않았다). `--faint`는 크레딧·부가 메타에만 쓴다(가장 밝은 천 위에서 3.8:1).
