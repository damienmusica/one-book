# paper-seal — 종이와 인장

**테제.** 모든 쪽은 한 권의 책의 표제지다. 밝은 종이(`--paper`), 먹(`--ink`), 그리고 붉은색은 오직 *찍힌 것*에만 쓴다 — 작가의 인장(우리가 출처에 대본 쪽)과 독자의 도장(당신이 표시한 책). 금색·상자·점선 괘선은 0개 — 점선은 '아직'(연필 인장, 빈 도장 자리)의 표시로만 남는다. 위계는 크기와 괘선과 여백이 만든다.

**타이포 사다리** (Noto Serif KR 400·600 하나, 데스크톱/모바일 px)
- 작품 제목 XL(3자 이하) 176/80 · 작가 이름 100/44 · 세로 원어 이름 90/48 · 가로 원어 이름 42/22
- 작품 줄 제목 30/23 · 입문 순서 서수 64/43 · 리드(why) 21/18 · 본문 17 · 보조 15 · 라벨 12~13.5(자간 .22em, 한글 자간이 스몰캡스를 대신한다)
- 최대:본문 = 10:1. 굵기는 지위다 — 600은 도판, 400은 스케치, 연필색은 실루엣.

**팔레트 토큰** — `--paper #f0e7cd`(라이브에 선언만 된 토큰을 깨웠다) · `--paper-hi #f8f2e2`(패널은 어두워지지 않고 밝아진다) · `--paper-lo #e4d8b8` · `--ink #2b2015` · `--ink-2 #574a39` · `--ink-3 #6f6250`(라벨, 4.8:1) · `--rule rgba(43,32,21,.2)` · `--seal #b4271b`(유일한 유채색) · `--pencil #8d8573`. 종이결은 인라인 feTurbulence 3% — 요청 0건.

**작가별 변수와 도출 규칙** (전부 graph.json 의 `o`·`i`·`d` 와 art/manifest.json 에서, `build.py: seal_glyphs()`)
1. **인장의 글자** = 원어 이름의 문자로. 한자·가나 → 이름 첫 글자(川·紫·屈·金) / 한글 → 음절 초성(ㄱㅅㅇ) / 그 밖의 문자 → 마지막 단어의 첫 자소, 대문자(K·А·Ц·م·ঠা). 틀(정사각·크기·붉은색)은 고정, 안의 글자만 변한다.
2. **인장의 상태** = 깊이. 도판 → 붉은 백문(찍혔다). 스케치 → 연필 점선 틀 + 빗금 글자(아직 새기지 않았다). 다른 작가를 가리킬 때는 먹색 — 한 쪽에 붉은 인장은 그 쪽 주인 하나.
3. **기울기·인주 얼룩** = FNV(slug) → 회전 ±4.5°, feTurbulence seed. 같은 K 도 같은 자국이 아니다.
4. **이름이 서는 방향** = 문자 체계. 한자·가나는 세로쓰기(紫式部가 족자의 낙관처럼 선다), 아랍·히브리는 RTL, 나머지는 가로.
5. **서명** = 있으면(59+3점) 원어 이름 아래 자필, 인장이 그 꼬리에 겹쳐 찍힌다. 확인: 카프카의 서명은 `/art/marks/franz-kafka.png` 에만 있고 `/art/signatures/` 에는 없다. 무라사키는 둘 다 없다 → 세로 이름 + 인장.
6. **제목 크기** = 글자 수 계급(≤3자 XL). 『변신』은 176px, 긴 제목은 자동으로 물러선다.

**일곱 과제** ① 위 1–6 ② 위 사다리 ③ 표시 장치 = 페이지에서 가장 큰 조작물(작품 쪽 64px 먹색 알약 + 5칸 사다리 + 모바일 하단 고정 바; 누르면 표제지에 붉은 도장이 찍히고 "서재에 꽂혔다"; 입문 1번만 채운 버튼, 나머지는 선) ④ 첫 장 = 펼친 책. 왼쪽이 표제지와 문(375×812 에서 y=256–323, 67px 입력+먹색 버튼), 오른쪽이 이번 주에 열린 쪽(오늘 ISO 39주 = 곰브로비치, 서명 있음). 없는 이름엔 말을 한다 ⑤ 판본 = 진짜 `<table>`(출판사·옮긴이·연도·저본·ISBN·문), 근거문은 행 아래 한 줄, 확인 출처는 더 작게, 한국어/원서 묶음; 모바일에서는 같은 표가 출판사+연도 / 옮긴이 / ISBN+44px 링크로 접힌다 ⑥ 스케치 = 머리의 연필 빗금 띠 "스케치 · 아직 출처에 대보지 않은 쪽" + 연필 인장 + 400 굵기 이름 + 연필색 연도; 색인에서도 항목마다 같은 연필 인장 ⑦ 375·1280 둘 다 브라우저 실측 — 여섯 쪽 모두 가로 넘침 0px, 표시 버튼 335×48(모바일)·218×64(작품 쪽)·하단 바 169×50, 내비 62×44.

**위험**
- 인장 글자 규칙은 "마지막 단어"라 세르반테스 사아베드라→S, 바르가스 요사→L 이 나온다. 별칭 데이터로 고칠 수 있지만 지금은 규칙 그대로 보였다.
- Noto Serif KR 에 그리스·아랍·벵골 자형이 없어 그 인장은 시스템 세리프로 떨어진다(기기마다 자국이 다르다). 제안: 인장용 글리프만 빌드타임에 SVG path 로 굽거나 Noto Serif/Naskh(OFL) 서브셋 추가. 600 위에 900 한 단을 더 얹으면 사다리가 더 가팔라진다(OFL, 이름 글리프만 서브셋).
- 밝은 종이는 밤 독서에 불리하다 — 다크는 `#2c3035`급 슬레이트 종이로 토큰만 갈아 끼우는 2차 작업.
- 새 문구 3개를 썼다(결함 대응 최소한): "서재에 꽂혔다." · "아직 없는 이름이다 — 색인은 지금도 열려 있다." · 색인 범례. 작가 쪽 산문은 0자 추가.
