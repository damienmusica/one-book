# 초상 사다리 — R9 결정 개정안 (초안)

**상태: 초안. 비준 전에는 어떤 데이터도 교체하지 않는다.**
발의: CPO 판정 (2026-08-20) · 기안: CTO · 대상: R9 상상-초상 파일럿

---

## 1. 무엇이 문제인가

R9 는 `data/portraits.json` 에 100/100 커버리지의 **상상 초상**을 도입하고
"상상 초상"이라는 카투슈 문구로 정직성을 확보했다고 판단했다. 실측 현황:

| | 수 |
|---|---|
| 얼굴(`mode: "face"`) | **87** |
| 사물(`mode: "object"`) | 13 (생존 7인 포함) |
| 권리 사다리 rung 1 / 2 / 3 | 39 / 54 / 7 |
| 검토 상태 | 100/100 `reviewed` |

개정 사유(외부 리뷰 지적 ③, CPO 판정으로 확정):

> "상상 초상"이라는 글자는 읽은 뒤에야 보이지만 얼굴은 즉시 실제 인물의
> 얼굴처럼 받아들여진다.

라벨은 사후 텍스트이고 얼굴 인지는 그보다 앞선다. 증거를 정체성으로 삼는
아틀라스가 **실존 인물 87인의 발명된 얼굴**을 최종 자산으로 배포하는 것은
문구로 회수되지 않는다. 또한 R11 브리프의 자산 커버리지 표가 이 87을
"보유"로 계산한 것은 회계 부정이었다 — 그 항목이 이 개정의 직접 계기다.

**이 개정은 R9 를 실패로 규정하지 않는다.** R9 는 사물-초상이라는 장르와
권리 사다리를 만들었고, 그 장치가 지금 해법의 재료다. 바뀌는 것은 사다리의
**최하단 기본값**이다.

## 2. 개정 조항

### 조항 A — 상상된 인간 얼굴 금지

> 실존 인물의 얼굴을 생성·합성·재현한 이미지는 **최종 자산으로 사용하지
> 않는다.** 초상 슬롯이 비어 있는 것은 허용되지만, 발명된 얼굴로 채우는 것은
> 허용되지 않는다. 이 금지는 라벨·카투슈·툴팁으로 면제되지 않는다.

### 조항 B — 4단 초상 사다리

높은 단이 있으면 낮은 단을 쓰지 않는다.

| 단 | 무엇 | 조건 |
|---|---|---|
| **1. 기록 초상** | 권리 확인된 실제 사진·회화·판화 | `provenance` + `licence` 필수, 상업 사용 가부 기록 |
| **2. 실제 문헌·사물** | 그 사람이 남긴 것 — 육필, 서명, 낙관, 초판 표제면, 사용한 물건의 실제 사진 | 동일 |
| **3. 근거 있는 사물 초상** | 실제 문헌에 근거한 사물 구성. 얼굴 없음 | `historicalBasis` 필수 — 어느 기록의 무엇에 근거했는지 |
| **4. 비인물적 활자 명판** | 원어명 + 생몰년 + 인장 글리프(원어 성씨 파생 활자) | 근거 불필요. **기본값** |

### 조항 C — 네 필드를 분리한다

한 필드가 네 가지를 뭉뚱그리면 무엇이 검증됐는지 알 수 없다.

```jsonc
{
  "authorId": "marcel-proust",
  "rung": 4,
  "reviewed": true,            // 편집 검토를 통과했는가 (사람)
  "historicalBasis": null,     // 무엇에 근거했는가 (3단 필수, 1·2단은 출처 id)
  "provenance": null,          // 어디서 왔는가 — 기관·컬렉션·URL·취득일
  "licence": null              // PD / CC-BY-4.0 / … + commercialUse: bool
}
```

- `reviewed` 는 **검토 사실**이지 근거의 존재가 아니다. 지금 스키마는 이 둘을
  구분하지 못한다.
- `licence` 에는 **관할**을 적는다(`PD-Japan`, `PD-US` 는 전역 PD 가 아니다).
- `commercialUse` 는 불리언으로 분리한다 — Noosphere 본체가 소스에 요구하는
  것과 같은 규율.

### 조항 D — 커버리지 회계

초상 커버리지는 **1·2·3단만** 센다. 4단 활자 명판은 커버리지가 아니라
**부재의 정직한 표시**다. 문서·리포트·브리프는 이 규칙을 따른다.

## 3. 집행 계획

| 단계 | 내용 | 상태 |
|---|---|---|
| P0 | R11 프로토타입에서 발명된 얼굴 렌더 중단, 4단 활자 명판으로 대체 | **완료** (본 라운드) |
| P1 | 스키마에 4필드 분리 + 검증 추가 | 비준 후 |
| P2 | 기록 초상 수집 파도 — R10 프로비넌스 원장 형식 | 비준 후 |
| P3 | 2·3단 자산(육필·서명·초판 표제면) 확보분부터 승급 | 비준 후 |
| P4 | 출하된 행성 앱(`index.html`)의 초상 경로 교체 | **비준 필수** — 출하 앱의 QA 계약을 건드린다 |

현재 R11 프로토타입은 1단 3인 + 4단 97인으로 동작한다. 2·3단은 자산 수집이
선행이므로 비어 있다.

## 4. 이 개정이 바꾸지 않는 것

- 생존 인물에 대한 더 엄격한 취급(R9 결정) — 그대로 상속.
- 사물-초상 장르 자체 — 3단으로 승격되어 유지된다.
- `data/portraits.json` 의 기존 레코드 — 비준 전에는 한 줄도 바꾸지 않는다.
