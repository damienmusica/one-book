# 낯선 5인 테스트 킷 — 단일 안 대 대조군 (2026-08-31 개정)

한 문장 계약: "다음 읽을 책을 못 고르는 독자가 15분 안에 '읽고 싶다' 하나를 담고,
일주일 뒤 스스로 돌아온다." 이 테스트가 그 계약의 유일한 판정 절차다.
**CPO는 세션을 진행하지 않는다** — 녹화를 보고 판정한다(주 15분).

## 참가자

- 낯선 사람 5인 (프로젝트를 모르는 사람. 가족·팀원 제외. 책을 "가끔" 읽는 사람 우선 —
  애독가만 모으면 대조군(위키)이 과대평가된다).
- CPO가 제공: 사람 5인 + 일정. **이것이 이 계획에서 CPO에게 요청하는 유일한 자원이다.**

## 절차 (1인당 ~20분, 화면+음성 녹화)

1. **도입(1분)** — 대본: "책을 하나 고르는 걸 도와주는 도구들을 보여드릴게요.
   생각을 소리 내 말해 주세요. 저는 도와드릴 수 없습니다." (그 이상 말하지 않는다.
   개입·힌트·변명 금지. 참가자가 막혀도 침묵.)
2. **과제(안마다 동일)** — "다음에 읽고 싶은 책을 하나 찾아서 '읽고 싶음'으로
   담아 주세요(대조군은: 제목을 종이에 적어 주세요). 다 되면 말씀해 주세요."
3. **순서(순서 효과 상쇄)**: 참가자 1·3·5 는 B→W, 참가자 2·4 는 W→B.
   - **B = `/` (하나의 책)** · **W = 대조군: 나무위키 문학 문서 + 온라인 서점
     검색** (브라우저 새 탭)
   - 2026-08-31 결정 (132)로 A(3D 성계)와 B(2D 성좌도)를 **판정 없이 삭제**했다.
     사전 등록된 3안 비교는 그 순간 해체됐고, 남은 것은 단일 안 대 대조군이다.
     이 비용은 `docs/one-sentence-contract.md` 「정직한 비용」 절에 기록돼 있다 —
     여기서 되풀이하지 않되, **결과를 3안 비교의 결과로 인용하지 않는다.**
   - 각 안 최대 8분. 8분 초과 = 그 안 과제 실패로 기록하고 다음 안으로.
   - 안마다 시작 전 시크릿 창(저장소 초기화)으로 연다.
4. **안별 기록(진행지)**: 시작 시각 / 첫 담기 시각 / 완수 여부 / 참가자가 소리 낸
   막힘 지점(원문 그대로) / 이탈 시도("이제 그만 봐도 되나요" 류).
5. **회고(둘 다 끝난 뒤, 3문항)**: ① "둘 중 다음 주에 혼자 다시 열 것 같은
   건?" ② "각각 뭐 하는 물건이었나?" ③ "가장 짜증났던 순간 하나."
   - ②는 **이름 문제를 공짜로 측정한다** — 「하나의 책」이 무엇인지 참가자의
     말로 되돌아오는지.
6. **재방문 측정**: 세션 후 아무 링크도 보내지 않는다. 7일 뒤 "지난주 그 도구들
   기억나세요? 그 후에 열어본 적 있나요?"만 묻는다(링크 재발송 금지 — 자발성 측정).

## 측정 시트 (참가자 × 안)

| 항목 | 정의 |
|---|---|
| 완수 | 8분 내 담기(또는 제목 기록) 성공 여부 |
| 첫 담기 시간 | 로드 → 담기까지 초 (녹화 타임스탬프; 보조: `localStorage.getItem('lp.metrics')`) |
| 막힘 수 | 10초 이상 무진전 + 발화된 혼란 횟수 |
| 재선택 | 회고 ①에서 이 안을 골랐는가 |

## 판정 규칙 (사전 등록 — 결과 보고 바꾸지 않는다)

- **안 간 판정**: 완수율 → 첫 담기 시간 중앙값 → 재선택 순으로 비교.
  A가 B/C에 완수·시간 모두 열세면 판결 §6-1 발동 검토(3D 종료).
- **제품 판정**: 최고 안조차 4/5 실패면 §6-2(전제 기각) 카운트 1.
  대조군 W가 모든 안을 시간·재선택에서 이기면 §6-5 카운트 1.
- 손 떼기 조건 전문: `docs/one-sentence-contract.md`.
