## Ⅱ. 책 선택을 실제로 일으키는 것 (증거 강도순)

1. **사람의 감정적 증언** — BookTok: 판례 최강(추적 작가군 1,300만→4,700만 부,
   16-25세의 68% "아니었으면 안 골랐을 책을 읽게 됨"); NPR Book Concierge 의
   최다 클릭 태그는 매년 Staff Picks; 손글씨 추천 카드 한 장이 무명작 81부
   (Waterstones 는 지점 큐레이션 전환으로 반품률 20%→한 자릿수, 흑자 전환).
2. **신뢰 관계 경유** — Goodreads 발견의 79%(오프라인 친구)/64%(사이트 친구),
   96%는 이미 아는 작가의 책을 읽는다.
3. **행동 인접성 + 결정 지점 배치** — Amazon 동시구매 추천(매출 ~35% 추정).
4. **마찰 제거: 유한한 수동 배달** — Discover Weekly 10개월 4천만 명, 절반이
   주 10곡+. 탐색을 습관으로 바꾼 것은 배달이지 탐험이 아니다.
5. **유사성 지도 단독** — 전환 증거 0 (Literature-Map 20년). **지도는 무대일
   뿐, 선택을 일으키는 것은 그 위의 증언이다.**

## Ⅲ. 지식 그래프 생존자 + 3D 의 과학적 판정

- 생존자 전원(Connected Papers 100만+, Litmaps, Inciteful, ResearchRabbit
  100만+, Semantic Scholar)이 **닻 우선**이다: 아는 항목 하나 → 완성된 국소
  지도 → 반복 확장. 자유 비행을 파는 곳은 없다. Litmaps 는 축에 의미를
  고정(연도×인용)했고, ResearchRabbit 2025 개편은 탐험 이력의 전면 전시를
  "압도적 클러터"로 판정하고 숨겼다.
- 3D 판정(30년 HCI): 추상 정보 과제에서 3D 가 2D 를 성능으로 이긴 기록 없음
  (Cockburn & McKenzie 2001: 모든 밀도에서 3D 평균 열세; 성능을 죽인 변수는
  차원이 아니라 **밀도**). 그러나 주관 선호·몰입·"구조의 감"은 3D 가 거의
  항상 이겼다. 닐슨의 합법 예외: **오락·교육 — 몰입이 효율보다 중요할 때.**

## Ⅴ. 방정식이 시키는 개조 (이 문서와 같은 커밋에 집행)

1. **닻 우선 입구** — B: 로드시 "아는 작가에서 시작" 오버레이(건너뛰기 가능),
   C: 시작 화면에 전 작가 닻 검색 추가. (Ⅲ 생존자 전원 패턴)
2. **증언의 결정 지점 배치** — 작품 페이지에 "이 책을 지목한 작가들의 증언"
   블록(작품 앵커 관계에서 파생 — 지어낸 것 0, 전부 기존 검토 데이터).
   마르케스가 『변신』을 증언한다 — BookTok 방정식의 우리식 정직 번역. (Ⅱ-1)
3. **유한 배달 훅** — C 에 "이번 주의 산책"(ISO 주차 결정론적 출발 작가):
   한 문장 계약의 "일주일 뒤 돌아온다" 절의 기제. (Ⅱ-4)
4. **A 의 재정위 가설(사전 등록)** — 판례상 A 의 생존 역할은 기본 항법이
   아니라 몰입 모드(기획전)다. 단, 이것은 예측이지 판결이 아니다 — 3안
   비교가 판결한다. 예측이 틀리면(낯선 눈이 A 를 과제에서도 선호) 이 문서에
   그렇게 기록한다.
